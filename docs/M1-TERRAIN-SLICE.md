# P0 M1：森林—岩壁—河岸 6×5 局部美术验收

> **v0.1.20.3：美术验收未通过。** 用户提供的 390×844 实机截图显示：重复岩石沿河岸排列、素材色调与透视不统一、草地与河水交界生硬。不能将本阶段标记为“美术完成”。

## 已核实改动与纠正

- v0.1.20.0 没有引入统一风格的新岩石/树木。只是以已有的一张岩石素材和一张树木素材在右岸重复摆放，额外叠加旧草地纹理的 46 单位小片、程序化水纹与湿土描边。视觉效果未达标。
- v0.1.20.1–.2 新增独立 Chromium 浏览器截图验收与手机默认镜头修订；浏览器自动化通过只证明加载和交互正确，不证明画风合格。
- **v0.1.20.3 已将 v0.1.20.0–.2 不合格的视觉实验撤回**：不再额外添加岸边重复的 8 组石块和 3 棵树，不再渲染旧纹理小片和假岸线装饰；地表绘制及原有可玩区场景恢复到 v0.1.19.5 的视觉基线。
- 保留真正有价值且不影响画面的部分：Chromium 截图验证、手机初始镜头优化、46 单位微瓦片地址及草土邻接纯数据辅助函数。这些数据函数**尚未接入正式的过渡资源图集**，不得以存在代码作为美术交付。

## 下一次实质性美术开发

1. 先确认半写实高角度俯视风格：统一主光照、色温、笔触、树/石比例、接地阴影，不再把战术障碍岩石简单缩小复制到河岸。
2. **只制作世界列 10–15、行 4–8 的 6×5 样片**（552×460 世界单位），提供多形态针叶树、岸岩直段/转角/端头与草土过渡的真正可复用素材。每一种应独立可替换、可辨别许可、可记录原始来源。
3. 以可拼接岸线而非线条叠加实现水陆衔接；不得使用整齐虚线、圆点模拟自然砾岸。
4. 先在 1920×1080、1366×768 和手机 390×844 视觉评审 M1 样片，确认没有明显重复、突兀色差、图块直缝、遮挡问题。
5. **样片人工批准后**，再将相同资产/拼接规则扩展第一关完整 16×12 舞台。无法验收则不进入全图铺设。

## 持续的技术边界

- 世界 16×12，每格 92；战术格仍为 10×8，地形、寻路、攻击、反击不变。
- 河水与岸边装饰不可触发棋格输入；游戏主地图与小地图必须共用同一场景数据。
- CI 与浏览器测试是功能回归，不是主观画质评分。真实玩家截图不合格即不能认定 M1 成功。

## 美术验收清单

- [ ] 6×5 河岸样片的岩壁、树木、岸线投影与调色统一
- [ ] 可复用的草/土、岸/水过渡贴片无方块接缝
- [ ] 不能连续复用一张高亮岩石图造成固定间距印章感
- [ ] 角色始终清楚可见，触控和小地图不被装饰层拦截
- [ ] 局部样片经人工确认之后再扩展整关
