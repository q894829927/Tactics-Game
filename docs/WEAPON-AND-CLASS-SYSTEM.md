# Wildfield Tactics · 七系武器与自由职业系统策划 V1.1

> **状态：V1.1 策划定稿；W0 通用追击已实现，W1及以后仍待开发。**  
> **制定：2026-10-14**；基线：`v0.1.20.9`。  
> 参考《火焰纹章：万紫千红》的系统设计思路，角色、职业名称、技能、数值及实现均为本项目自有方案。  
> **V1.1 关键修订：所有具备攻击行为的物理武器与攻击魔法在攻速差 ≥4 时可追击；剑不是唯一能追击的武器，仅对剑系追击伤害提供 ×1.2 特化。**

## 1. 当前代码基线和迁移边界

- 现有 TypeScript 战斗引擎位于 `src/engine/battle.ts`，独立于 DOM/CSS 战场；10×8 战术格、4我方6敌方、加权地形移动、可撤回试移动、攻击/反击/追击、固定随机种子、经验与战斗预测已经存在。
- `src/engine/weapons.ts` 目前是16件静态武器；`Weapon.kind` 只区分 physical / magical，职业与具体装备清单绑定，未有物理拳套、独立黑白魔法、实例耐久或武器熟练度。
- `src/engine/attributes.ts` 已有速度、体格、力量、魔力、魔防、技巧、幸运、成长率、等级经验；保留其基础数学关系，只重构职业叠加和修饰器。
- **W0实施（v0.1.20.11）：** `forecastAttack` 与 `strike` 共用 `src/engine/followUp.ts` 的门槛≥4；旧版≥5只属于历史实现。拳套、攻击型白魔法、耐久与职业等后续系统尚未开发。
- 现有正常操作“选中角色→确认移动→指令→攻击/背包/待机→预测→确认”，以及手机返回、电脑右键撤销、敌我蓝色移动格与红色攻击格预览均需保留。
- `docs/GAME-DESIGN.md` 的旧MVP段落属于历史实现记录；**未来玩法规则以本文为准，代码何时切换以对应开发阶段验收为准**。

## 2. 武器类型、标签与全字段

### 2.1 七系固有能力

| 武器系 | 标识 | 固有能力及细节 | 对应目标/限制 |
|---|---|---|---|
| 剑 | sword | 实际使用剑发动的**追击那一击**：伤害×1.2，向下取整；追击门槛仍统一≥4 | 不影响首击、一般反击、非剑追击 |
| 枪 | lance | 对具有 Cavalry 标签的目标**武器威力×2**，再参与防御结算 | 不翻倍力量；对非骑乘无特效 |
| 斧 | axe | 命中后该次伤害在必杀前至少为5；未命中为0 | 保底允许与必杀相乘 |
| 弓 | bow | 对 Flying 标签目标**武器威力×3** | 基础弓射程2；长弓可特例射程3–4，距离1通常不能反击 |
| 拳套 | gauntlet | 受到非拳套攻击（含攻击型魔法）时，**回避+15** | 只对需要命中判定的直接攻击；不自动双击 |
| 黑魔法 | dark | 魔力攻击魔防，配置减益/元素等独立法术效果 | 需要当前职业权限、黑魔法熟练度、剩余次数 |
| 白魔法 | white | 治疗、净化、增益；少数白魔法可作为攻击法术 | 治疗/辅助不触发追击，**攻击型白魔法可按≥4追击** |

**统一限定：**“可追击”与“必定命中”不是一回事，攻击可能落空。普通法术、攻击型白魔法、剑枪斧弓拳套一律参与攻速差判定。装备的武器/法术不可用、距离不合法、单位死亡或技能明确禁止追击时，不执行追加攻击。没有额外拳套双击机制。

### 2.4 耐久与法术次数

- 普攻、普通反击、**因攻速差≥4产生的普通追击**都不耗耐久。
- 物理战技在攻击正式提交时扣指定耐久，未命中照扣。耐久不足则不可选，耐久不能负数。
- 耐久0时物理武器仍可普攻/反击/追击，威力-3（最小0）、命中-20，且不能使用耗耐久战技；五系固有效果仍按实际武器类别判定。
- 单次发起法术攻击或反击，消耗该法术1次；**由该次施法交战引发的追击不再扣一次**。若已有1次法术剩余，允许首击与一次合法追击。
- 白魔法每次治疗、增益或净化成功提交消耗1次；满HP且没有其他有效目标效果时不能通过空治疗刷经验。
- 攻击型黑/白魔法的战技可明确消费2次法术次数；具体效果覆盖默认1次，不重复扣费。
- 战斗预览、试移动与取消不消耗任何耐久、次数、经验或伪随机数；正式提交必须原子消费。
- 法术次数在战后整备恢复，物理武器耐久通过金币修理恢复。

## 3. 通用攻速、追击、反击与伤害（V1.1 修订核心）

### 3.1 攻速计算

`AS = max(0, Speed - max(0, EquippedWeight - Build))`

速度来自角色基础值+当前职业补正+有效状态；重量取**当前实际攻击/反击使用的武器或法术**。攻击型白魔法也有重量，治疗/辅助法术不会进入攻击事件。

`ΔAS = AS_attacker - AS_defender`

- `ΔAS >= 4`：攻击方获得一次追击资格。
- `ΔAS <= -4`：防守方获得一次追击资格，**但只有能合法反击时才可能实际执行**。
- `-4 < ΔAS < 4`：无追击。
- 差值正好4/-4有效；攻速相同无追击。
- 一次交战最多一个追击方、一次追加攻击；不得无限追击或引发额外多轮反击。
- 具有攻击资格的剑、枪、斧、弓、拳套、黑魔法、**攻击型白魔法**一视同仁。
- 治疗、护盾、增益、净化等非攻击行为既不追击也不触发普通反击。
- 战技默认允许追击；`followUpPolicy=forbid` 才禁用。其他战技若修改攻击次数须另立设计与验收，不与本系统混用。

### 3.2 战斗顺序及边界

1. 发起方合法首击。
2. 防守方在仍存活、攻击者进入合法射程、具备可用攻击武器/攻击法术与次数时进行一次反击。
3. 双方仍存活、有效装备/法术可用且追击资格未禁止，则攻速高的一方进行一次追击。防守方的追击要求其曾具备合法反击资格。
4. 若对方在前一击倒下，后续击打跳过。反击方的装备、距离、次数在交战开始时确定，后续事件按真实状态校验。
5. 每个攻击事件独立进行命中与必杀判定；追击不保证命中。
6. 反击方远程合法性包括弓/法术最小射程，不能因为AS领先就跨越距离限制。
7. 剑追击奖励在该次真实使用剑攻击命中后生效，对枪/魔法等追击不附赠加成。

**定稿例子：** 剑士AS12、持斧敌人AS8：剑士追击；攻击魔法AS10对持枪敌人AS6：术师也追击；弓手AS11对贴身敌人AS6：若距离1无法合法发动攻击或反击，则不因为AS差5强制追击；进攻方AS7、防守方AS12且能反击，则防守方在反击后再追击一次。

### 3.3 结算公式与严格优先级

1. 资格：阵营/存活/行动状态/职业装备资格/资源/范围/目标。
2. 生成纯只读`CombatContext`，冻结本次装备、角色状态、地形、战技与法术。
3. 面板攻速：`AS` 按上式计算；判断门槛 `abs(ΔAS) >= 4`。
4. 有效武器威力：枪对Cavalry×2、弓对Flying×3；只倍增武器本身威力，不倍增力量/魔力。不同目标标签不叠乘多种武器系倍率。
5. 攻击基础：物理 `max(0,Strength+EffectiveMight-PhysicalProtection)`；魔法 `max(0,Magic+SpellMight-MagicalProtection)`；目标地形修正已包含在防御。
6. 加入战技、职业固有、特技及临时状态的伤害修饰，进行叠加组和上限判定。
7. **斧最低伤害**：在命中后、必杀前对该次非负伤害应用 `max(5,damage)`；未命中为0。不能透过“固定零伤害、完全免疫”的专门规则，未来如加入免疫需显式定义优先级。
8. 命中与必杀：`HitChance=clamp(WeaponHit+2*Dex+floor(Luck/2)+HitModifiers - (2*AS+floor(Luck/2)+AvoidModifiers),0,100)`；`CritChance=clamp(WeaponCrit+floor(Dex/2)+CritModifiers -(TargetLuck+TargetWeaponDodge+CritAvoidModifiers),0,100)`；最终以既有引擎的命中/必杀字段统一计算。
9. 单次命中若必杀，伤害×3；**如果本次是剑系追击**，之后再×1.2且向下取整；普通非剑追击不乘1.2。
10. 逐次扣减HP、记录伤害和状态触发；有效目标和资源按已冻结行动语义消费。
11. 交战最终提交职业经验/武器技能经验/角色经验/回合动作与事件。预测只读取快照，不消耗RNG。

**优先级例子：** 剑追击普通伤害11且必杀时，先得33，再 `floor(33×1.2)=39`；不改变前一击伤害。斧基础伤害2，命中后变5，若必杀则15；未命中为0。

### 3.4 追击与战技默认表

| 攻击类型 | 可按AS差≥4追击？ | 特殊规定 |
|---|---|---|
| 剑普通攻击 | 是 | 追击那一击×1.2 |
| 枪/斧/弓/拳套普通攻击 | 是 | 对应固有能力不变 |
| 黑魔法普通攻击 | 是 | 法术须有次数与合法射程 |
| 攻击型白魔法 | 是 | 同上，攻击型才有追击资格 |
| 纯治疗/增益白魔法 | 否 | 无攻击事件 |
| 一般攻击战技 | **默认是** | 按其当前武器/法术，且资源足够 |
| 明确标注“不可追击”的战技 | 否 | 如定点射、裂甲击可按技能说明禁追击 |
| 防守方反击 | 可 | AS领先≥4且反击合法时再追加一次 |
| 自动攻击或回合外效果 | 默认否 | 未来必须另有规则批准 |

## 4. 自由职业：层级、资格与完整名录

### 4.1 通用职业结构与认证

每种职业提供：`statModifiers`、`growthModifiers`、`weaponPermissions`、`innateAbilityIds`、`masteryRewardIds`、`weaponExpBonuses`、`movementRules`、`unitTags`、`requiredLicenses`、`masteryThreshold`。

| 层级 | 最低主熟练度 | 名声 | 首次考试物品 | 考试金币 | 开放节奏 |
|---|---|---:|---|---:|---|
| 初级 | E | 0 | 无 | 0 | 开局 |
| 中级 | D | 30 | 中级凭证×1 | 150 | 第二章 |
| 上级 | B | 140 | 上级凭证×1 | 350 | 第五章 |
| 最上级 | A | 320 | 最上级凭证×1 | 700 | 第九章 |
| 传承 | S | 600 | 专属凭证×1 | 1000 | 后期任务 |

- 等级为建议培养阶段而非硬转职条件；资格主要由熟练度、名声、职业解锁、许可和凭证决定。
- 双专精职业必须同时满足其主、副专精，不可用其他武器技能替代。
- 首次合格认证**无随机失败**；成功后该角色永久拥有资格，之后战前整备自由切换，不重复消费费用或凭证。
- 角色个人属性/成长率和所有已练的技能与职业经验永久保留，职业补正只在当前职业生效；转职不直接永久加基础属性。
- 骑乘、飞行是单位类型标签（Cavalry/Flying），由当前职业等实际状态决定，枪/弓据此判定特效。
- 角色个人等级继续1–99，职业等级不取代个人等级；职业补正成长率随当前职业变化，每次升级只结算一次。

## 5. 武器技能经验 E→S+、职业精通与可继承能力

### 5.1 武器熟练度

| 等级 | 累计武器技能XP | 典型奖励 |
|---|---:|---|
| E | 0 | 基础武器、基础法术 |
| D | 40 | 初阶战技、中级认证 |
| C | 120 | 钢制武器及更高级法术 |
| B | 260 | 精制武器、上级认证 |
| A | 450 | 大师武器、最上级认证 |
| S | 700 | 稀有武器、传承资格、高阶战技 |
| S+ | 1000 | 武器系终极精通，不强制解锁更高伤害武器 |

每人独立记录七项累计XP；转换职业不清零。武器基础等级门槛以D、C、B、A、S为准，S+主要提供精通被动。

| 合法行为 | 武器技能XP |
|---|---:|
| 主动普通攻击 | +4 |
| 合法有效反击 | +2 |
| 主动使用物理战技 | +6 |
| 合法使用黑魔法攻击 | +4 |
| 有效白魔法治疗/辅助/攻击 | +4 |
| 同一次交战中的追击 | **不额外重复计XP** |

当前职业指定专精的XP获取增加25%，最终向上取整。未命中的合法主动攻击可获得技能XP，但空治疗、非法行动、预览不获XP。黑魔法/白魔法攻击中的追击与物理武器追击保持同样的“不额外刷经验”规则。

### 5.2 职业精通

| 职业级别 | 精通职业XP |
|---|---:|
| 初级 | 80 |
| 中级 | 120 |
| 上级 | 160 |
| 最上级 | 200 |
| 传承 | 240 |

职业XP获得：主动普通攻击+8，有效反击+4，职业战技+8，有效治疗/辅助+8，实际上阵且存活的首次关卡完成+6；单纯待机0。一次交战因追击不额外叠加一次主动职业XP。一个职业精通奖励每角色只发放一次；重复选择同职业不重复领奖。

武器熟练XP≠职业XP≠人物等级EXP，三条进度分别持久保存。每项独立累计、独立结算与校验。

### 5.3 特技和战技槽位

- 初期：可继承被动2槽、主动战技1槽。
- 角色等级达到10：可继承被动3槽、主动战技2槽。
- 当前职业固有特技1个独立槽位，自动生效；武器固有能力自动生效，不消耗槽。
- 职业精通奖励、武器熟练度被动只有**装备**到有限槽位才生效。
- 相同被动不重复装备，同一叠加组取最大值；可继承被动提供的命中/回避合计各不超过+20、直接伤害合计不超过+4。
- 转职后已学技能保留，但无法满足新职业武器权限的**主动战技不能装备和发动**。已有被动若明确要求某系武器，换武器后自然不触发。
- 可通过战前整备配置槽位，战斗中不可任意交换已装备的被动。

**技能等级奖励示例（剑）：** D剑术基础（剑命中+3），C剑术精进（剑回避+4），B剑术专家（剑主动伤害+1），A迅刃（剑追击命中+5），S剑术宗师（剑必杀+5），S+剑术极意（剑追击伤害额外+1）。S+不改变通用追击门槛。

### 5.4 七系基础战技（正式初稿）

| 类别 | 战技 | 熟练度 | 消耗 | 玩法效果 | 追击政策 |
|---|---|---|---|---|---|
| 剑 | 疾刃 | D | 耐久3 | 命中+10、伤害-1 | **允许，AS差≥4**；若追击用剑，仍享1.2 |
| 枪 | 截步刺 | D | 耐久4 | 命中后目标下次移动力-1 | **允许，AS差≥4** |
| 斧 | 裂甲击 | D | 耐久4 | 对重甲额外伤害+2 | **禁止追击（技能特例）** |
| 弓 | 定点射 | D | 耐久3 | 原地发起，命中+15、伤害+1 | **禁止追击（技能特例）** |
| 拳套 | 虚步击 | D | 耐久3 | 本次伤害-1，攻击后回避+10至下次己方回合 | **允许，AS差≥4** |
| 黑魔法 | 蚀弱咒 | C | 对应法术次数2 | 命中后目标防御-2至其下一次行动结束 | **允许，AS差≥4** |

**重要：**除“禁止追击”或“非攻击行为”的明确例外，任何新战技默认遵循≥4，不得套用旧版“所有战技默认不追击”。若某次战技首击结束后能追加攻击，追击作为该次战技交战里的**普通追加攻击事件**：其伤害按照武器固有与当前状态计算，不再次执行一次减益/附加目标位移，也不再扣第二笔战技耐久/施法费用。剑系追击的1.2仍适用。

## 7. 数据结构、触发时机与系统边界

### 7.1 持久数据

- `CharacterProgression`：角色ID、个人Lv/EXP、永久基础属性、永久成长率、七系武器技能累计XP、各职业XP、已认证职业、已解锁被动/战技/法术、已装备槽位、当前职业ID、持有装备实例ID。
- `ClassDefinition`：职业层级、属性/成长补正、可用武器系、主副熟练门槛、名声门槛、认证凭证、职业固有特技、精通阈值/奖励、武器经验加成、移动规则、Cavalry/Flying标签。
- `WeaponDefinition`：静态全字段；`WeaponInstance`：实例ID、定义ID、当前耐久、锻造级别、所有者；`SpellDefinition`：法术效果、射程、次数、消耗与目标。
- `PassiveDefinition`：效果ID、触发条件、叠加组、上下限；`CombatArtDefinition`：合法武器、熟练度、消耗、是否禁止追击（默认false）、资源消耗时机、附加状态。
- `CampaignEconomy`：金币、名声、考试凭证、首次任务奖励领取记录。

### 7.2 战斗临时数据

- `BattleUnitState`：位置、当前HP、行动状态、装备实例、法术剩余次数、有效状态、职业/个人实际合成属性。
- `CombatContext`：冻结当前攻击者/防守者、攻击行为类型、武器/法术、属性/状态、地图格、射程、AS、`followUpThreshold=4`、预计反击与追击事件。应为纯只读对象。
- `CombatEvent`：发起攻击、反击、追击、命中/必杀、HP变化、减益、资源消耗、经验结算；区分`follow-up`以便剑系×1.2与UI标示。
- `StatusInstance`：状态来源、起止回合事件、层数、清除规则。新状态不能依靠动画计时或页面DOM状态推算。

### 7.3 规则优先于UI

只在战斗引擎一处配置 `FOLLOW_UP_AS_THRESHOLD = 4`；预览、玩家结算、敌军AI、战术提示、模拟、回归测试均调用同一判定器。不得分别在 `forecastAttack` 与 `strike` 写两份不同阈值；不要用渲染层直接估计追击。单位使用哪一类武器与是否有可用攻击魔法必须由真实数据解析，不能靠职业图标判断。

## 8. AI 适配与战术体验

敌军AI首先枚举所有合法终点、武器/法术、目标与可用战技，调用**同一战斗预览器**评分；禁止产生非法射程攻击、无次数反击或错误的“只有剑能追击”判断。

建议初始AI评分权重（后续基于实际战斗调参）：

| 评价项 | 值 |
|---|---:|
| 可稳定击倒一名敌人 | +35 |
| 单次期望净伤害 | 每点+3 |
| 敌方合法反击的期望损失 | 每点-2 |
| 自己可能被对方AS差≥4追击 | 风险值-8（若受击可活） |
| 自己合法获得AS差≥4追击 | +8（仍应计入净伤害，不重复无限叠分） |
| 防守关键据点 | +15 |
| 战技资源成本 | 以耐久/次数等价值换算，通常-2至-10 |

战术测试至少包含高速法师追击枪兵、高速弓手追击非贴身目标、剑追击额外加成、斧保底对重甲、枪对骑兵、弓对飞行、拳套回避，以及黑白魔法无次数时不合法。

## 11. 冻结、调参与变更控制

**锁定不可在没有新策划授权的实现中改动：** 七系身份及固有能力；没有武器三角；**全七系合法攻击攻速差≥4即可追击**；剑仅追击伤害×1.2；物理仅战技耗耐久；黑白魔法独立次数；自由转职与独立职业精通；职业装备权限不可被熟练度绕过；有限槽位；预览纯函数；动作原子提交。

**允许在平衡测试后调整：** 单件武器威力/命中/重量/价格、职业补正、XP阈值与获得速度、战技耐久消耗、金币奖励。调整必须同步策划数值表和可复现测试。

**实施边界：** W0已将当前可用物理武器与攻击魔法的统一追击门槛调整到≥4，剩余W1/W2等阶段的剑系追击增伤、特效、拳套、白魔法、耐久与自由职业等均属未来目标，不得视作已实装。
