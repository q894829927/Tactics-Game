# C1：自由转职与职业属性系统 · 实施说明

> 功能版本：**v0.1.25.0**。此阶段在现有单关卡上提供**战前转职**，不等于职业精通、职业技能、金币掉落、第二关或跨关卡存档已经开放。

## 实施范围

- 新增 `src/engine/classCertification.ts`：玩家可选职业名单、认证资格、名声与凭证/金币数据模型、一个临时训练武器槽位策略。
- 扩充 `CLASS_LIBRARY`：原有6种职业数值保持不变；可选初级职业共7种（剑士、枪卫、斧斗士、弓手、拳斗士、术士、见习祭司）；新增中级「游剑士」「壁垒卫士」资格与数值。敌方「步兵」「指挥官」及骑/飞测试模板不可供玩家选择。
- 新增 `Battle.changeClass` 和 `Battle.classStatus`，资格校验在整个切换操作前完成；`Unit.classLicenses` 为**角色独立永久认证列表**（在本次战斗/重新选职业期间保留）。
- 修改战斗面板的 `combatStats`、`damage` 和升级公式：职业属性补正/成长补正仅在使用时由纯函数临时计算。角色`stats`/`growths`是不可被转职永久改写的个人进度。
- 新增桌面右侧「职业整备」入口、设置中「职业整备」入口，以及可在手机设置中打开的自适应整备弹窗。弹窗选择人物/职业、展示资格与补正，确认后同步地图职业图标与数值。

## 职业资格与资源

| 层级 | 条件 | 认证 | 可用状态 |
|---|---|---|---|
| 初级7职业 | 该武器系E级 | 初次免费，认证永久保留 | 第一回合行动前可用 |
| 中级游剑士 | 剑术D、名声30、中级考试凭证1、金币150 | 成功后永久保留，无随机考试 | **校验已实现，正式游戏暂不提供凭证/金币获取入口** |
| 中级壁垒卫士 | 枪术D、名声30、中级考试凭证1、金币150 | 同上 | **校验已实现，暂未开放获取资源** |
| 上级/最上级/传承 | 见完整策划 | 尚未实现 | 不开放 |

资源与等级检查全部通过后才原子扣除金币与凭证；失败不改任何装备、职业、属性和资源。已认证职业无需再交考试费用，且必须满足武器系等级要求。名声为全局记录，认证不消费名声；金钱/凭证为准备阶段公用池，但现阶段默认都为0，无法通过关卡获得，相关奖励属于E1/C2。

## 不造成软锁的训练装备

转职后先搜索角色自己的背包，选择**当前职业许可并满足P1熟练度**的现有武器；若没有，自动提供一件基础训练武器（铁剑、铁枪、短斧、铁弓、练习拳套、火焰术、光矢术，全部E级）。

训练装备**只使用一个可替换的临时槽位**：开始3件物品的角色变成最多4件，不会每次切换都复制武器，也不会覆盖持有的钢制等原始武器；同一角色返回原职业可恢复使用原背包。魔法剩余次数为0时转职不会重置次数。训练装备不参与出售/交换经济（E1阶段规划更正式的仓库和补充机制）。

## 职业属性与成长

当前职业的数值补正仅是`effectiveClassStats(personalStats,classId)`和`effectiveClassGrowths(personalGrowths,classId)`计算结果；切换多次后个人能力不增不减。升级在真实结算时使用当前职业修正后的成长概率，升级产生的成长永久写入个人属性。没有通过反复转职获得立即永久属性的通道。

| 职业 | 当前属性补正 | 升级成长率补正 |
|---|---|---|
| 原剑士/枪卫/弓手/术士 | 0（保证现有首关原数值） | 0 |
| 斧斗士 | 力量+1 | 力量+5个百分点 |
| 拳斗士 | 速度+1 | 速度+5个百分点 |
| 见习祭司 | 魔力+1 | 魔力+5个百分点 |
| 游剑士（中级） | 速度+2 | 速度+10个百分点 |
| 壁垒卫士（中级） | 防守+3 | 防守+10个百分点 |

个人最大HP、当前HP、等级、普通人物经验、武器熟练度E～S+、装备耐久与魔法次数，在切换职业时均保留。职业移动速度/骑飞地形、专属固有技能、职业经验/精通仍待后续阶段。

## 整备窗口与单关限制

- 仅第一回合玩家第一次正式移动、攻击、待机、主动结束回合**之前**能够转职。
- 开始移动以后，即使取消这次移动，也不能再进入战前整备；避免移动范围、行动状态和装备预览在半途发生冲突。
- 转职不消耗玩家本回合行动，也不产生技能经验或战斗随机数消耗；敌方单位、测试骑兵/飞兵职业不可操作。
- 转职对当前装备权限立即生效；若原装备不再允许使用，自动切换到合法装备或借用E级训练装备；W0追击≥4、W1固有、W2耐久与次数、P1双重装备资格均保持一致。
- 本项目目前只有一关；重开关卡会将本关角色职业和证书重置到初始状态，**不是正式跨关存档**。C2/E1需要把职业认证、物品、金币和职业经验持久化。

## 验收范围

1. 不同角色的认证相互独立；已认证职业再次转入不重复收费。
2. 无凭证/名声/足够熟练度时不可认证中级；失败原子无副作用。
3. 新初级转职技能类型和默认训练装备合法，不破坏原3件起始装备。
4. 多次来回转职不叠加属性、不清空武器XP，不刷新已耗尽魔法次数。
5. 当前职业的属性和成长修正反映在战斗、预览、升级和UI中。
6. 确认移动、攻击、待机或结束回合后锁定战前整备。
7. 电脑/手机面板和弹窗交互可用，原4v6单位、位置、胜败与W0～P1测试不回退。
