# v0.1.5.0 分层地图接入

旧整张环境底图与旧小地图图片已退出运行时。当前地图由可复用地表材质、独立透明树木、独立透明岩壁及程序绘制的道路/缓坡/河水组装。

## 实际资源与组织

- [运行时素材目录](../public/assets/maps/red-banner/modular/README.md)：三张原始 PNG，来自 v0.1.4.3 的原创样张，复制时保留全部像素和 Alpha。
- `src/scene/GroundPainter.ts`：2× 静态地表 Canvas，以羽化重叠的 384 单位材质块减少硬接缝；不旋转或镜像带方向光的材质。道路、可走缓坡及外围河水由单独绘制步骤生成。材质载入失败仍显示程序地表。
- `src/scene/mapScenery.ts`：依据 `Battle.terrain` 为每个森林/峭壁格生成对应景物，外围树林与河岸岩壁不侵入可玩区。每个景物有文件、位置、大小、脚点及稳定 ID；同一地图重复生成布局一致。
- `src/scene/BoardView.ts`：地表、独立景物、地形提示、点击区、行动范围、单位及屏幕标签保持独立图层。树木/岩壁均位于单位与行动提示之下，不接收鼠标输入；单个景物载入失败只移除该图片。
- 小地图复制实际地表 Canvas，再复用同一份景物数据摆放缩略精灵；单位点和镜头框继续实时更新。没有另外绘制的小地图背景文件。

## 规则边界

完整舞台仍为 1472×1104，战术区仍为 10×8、原点 (276,184)、单格 92。河水、外围岩壁和树林不增加可走格。丘陵仍为可进入的地形，两个 `#` 峭壁格继续不可进入。移动、攻击、反击、出生点及结算没有改动。

## 验证与剩余范围

测试覆盖地形与精灵一一对应、全部装饰不覆盖战术区、河岸边界、布局确定性、PNG 字节与原图一致和 Alpha 类型。浏览器验证记录及截图放在 `art/map-integration/v0.1.5.0/`。

本版是分层地图的首版接入。正式 46 单位微瓦片与完整过渡图集、多个独立树型、岩壁内外角/端头、桥梁及营寨美术仍需继续制作。样张只有三种，重复感和装饰区岩壁衔接仍有优化空间；技术接入及交互检查不等于最终美术已获用户验收。
