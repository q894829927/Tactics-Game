# C4-1D：四关真实行动与培养经济平衡验收

状态：实战采样框架已建立，尚未宣布平衡通过。

## 方法

- 使用 Battle 正常战前整备、出击、移动、攻击、待机、敌军回合、结算和职业认证。不得人工设置 HP、位置、钱、职业经验或胜利。
- 脚本：scripts/c41d-balance.mjs。固定种子7、19、37、73，分别使用初始职业、合法自然转职、及首胜后再重玩两次三种实验条件。
- 每关有35回合上限。结果包含 victory/defeat/timeout；失败和超时不是胜利，也不凭空取得奖励。
- 统计每关成功样本的回合数、攻击和伤害、存活人数、耐久使用、职业经验、解锁精通、认证费用及当前金币/名声/凭证。
- 自动工作流 C4-1D Campaign Balance 保存 balance-artifacts/c41d-metrics.json 和 c41d-report.md，便于逐种子复核。
- 本策略是简单的贪心移动/普攻策略，未使用主动治疗和复杂战技，其胜率不能替代真人或最优策略；若没有完成样本，不得假设必须反复刷简单关卡。

## 验收口径

1. 至少有不强制修改状态的四关通关样本，才对通关回合与无刷关可行性下结论。
2. 只有实际获得的金币、名声和凭证才进入余额；认证由真实资格检查且消费150金币/1张券。
3. 精通门槛：初级80、已有中级120，必须用实际参战行动测到达时间，不能仅凭奖励表推算。
4. 两张不同关卡重玩获一券；第一关重复两次并不会凭空产生重复刷券收益。
5. 当前 C4-1C 理论四关首通合计为1220金、225名声、6券，但“理论总额足够”不证明关卡可过。
6. 若缺少合法通关样本，优先完善 AI 操作或实机回放，再修改数值；当前尚无修理与商店价格模型。

## 执行

Node.js 24：npm run verify；node scripts/c41d-balance.mjs。
CI 与独立实战报告应同时通过，ECS 版本另核对 SHA。
