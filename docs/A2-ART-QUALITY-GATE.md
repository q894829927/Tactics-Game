# A2 美术质量差距与重做门槛（待执行）

> 状态：**未完成美术重做**。2026-10-13 用户明确反馈：A2-2 SVG 和确认的参考图差距过大。这里是正式的质量问题记录，不是合格声明。

## 当前明确存在的问题

- SVG 以几何形状拼出树林、帐篷、岩壁、河水，看起来像简化示意，不具备暗黑奇幻场景所需的真实材质、树冠体积和空间深度。
- 地表仍暴露大量 92px 的重复纹理块，边界断裂；河道与石岸过渡单薄，营寨像图标而非场景。
- 岩壁/木桥/森林之间缺乏统一的光照、比例、透视与投影，远离目标图的半写实绘画质感。
- A2-3 小地图可以同步现在的素材布局，但它本身不能提升素材画质。

## 视觉重做方向（在 A2-4 前优先实施）

1. **原创半写实地形母版**：统一高角度俯视、左上暖光、右下冷影，参考图仅作为风格和场景布局目标；生成/绘制场景中的独立树林、地表、崖壁、营寨、河岸、木桥等素材，禁止使用一张带 UI 的参考大图替代游戏地图。
2. **体积与纹理**：林冠分前中后景，树干和脚点清晰；岩崖分顶面、立面和投影；河水有深浅变化、岸线、泡沫与连续流向；桥与河岸能自然连接。
3. **地形衔接**：以透贴地面边缘/网格外的装饰层遮盖方形接缝，但不能干扰 10×8 可玩规则；水与桥仍属于棋盘外不可走区域，直到规则实现。
4. **资产质量与授权**：原始图片有可追溯的制作来源；尽量统一 2× 甚至更高的导出质量，在缩放 60%/100%/185% 下仍能辨认。优先可独立替换的透明纹理与环境绘制素材。
5. **验收**：1920×1080 / 1366×768 的实际浏览器截图与目标图对照，按森林/岩壁/河流/桥梁/营寨/地图边缘六项逐一检查，**仅技术上加载成功不能算美术完成**。

当前 12 个 SVG 只用于保底与开发验证，不得在项目里标注为最终视觉资源。真正的美术通过验收后才能推进 A2-4 综合回归及后续阶段。
