# S1-0 主动战技与行动结算框架（v0.1.31.0）

## 完成边界

- 本阶段提供类型化 `ActionSpec`、只读 `previewAction`、集中式 `canPayActionCosts/payActionCosts`（预检查全部费用再一次支付）和 `lastActionEvents` 动作收据。
- 普通物理攻击零耐久、魔法攻击交战扣1次、W2样例战技扣3点耐久；样例被明确标为「战技·试验」，可以从指令菜单选择武器、选择目标、查看预测费用、取消、确认。**样例不是七系正式战技，不加入人物精通、技能解锁或职业表。**
- 玩家与敌方攻击共用动作预检/提交，敌方反击法术在真实合法反击发生时扣一次；追击不重复扣费。攻击者的耐久在发起攻击前扣除，但本次战斗读取付款前的武器属性快照，避免耐久归零立即削弱本次攻击。
- 新增动作收据标识 `confirmed` / `resource` / `strike`，既有 `lastCombatEvents` 继续用于地图战斗演出。无效指令及预测不消费次数、耐久、行动、随机数或经验。
- 旧版 `forecastAttack`、`useCombatArt`、普通 `click` 和敌军分步队列 API 保留，避免原4v6地图和移动撤回回退。
- 不新增治疗、灼烧、缓足、护卫、法阵、任何新的职业或能力；复杂伤害/状态效果遵循未来 S1-2/S1-1 和职业V2规则，而不是在本次偷偷上线。

## 核心行动管线

```
选择单位/武器/试验战技 → 只读规格及费用预检 → 纯预测 → 取消（零副作用）
  → 确认时再校验 → 原子支付（物理耐久/法术次数/预留HP）
  → 主动首击 → 合法反击（法术第一次反击时扣次数） → 合法追击
  → 事件与XP归档 → 播放动作/伤害演出
```

动作消耗统一保留 `durability`（按实例ID）、`spell`（按法术ID）、`hp`（不能支付到0），费用组合先全量检查再扣除。S1-0只允许标准攻击与既有 `w2-power-strike` 测试战技；未来新战技由独立注册表、学习条件、武器许可与槽位系统接入，不能仅传入任意字符串绕过权限。
