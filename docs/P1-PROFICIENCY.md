# P1 · 七系武器熟练度 E–S+ 与装备资格（v0.1.24.0）

> 已接入角色个人数据、实际战斗经验与装备判定；当前仍为单关卡原型，重开关卡会重置人物状态，跨关卡存档归后续阶段。**本阶段不会开放自由转职或职业精通。**

## 一、独立熟练度与阈值

每个角色的 `weaponExp` 是七项独立累计整数：`sword, lance, axe, bow, gauntlet, dark, white`。不清零、不同武器系互不转换、战斗时随当前使用武器系增长。

| 熟练度等级 | 累计经验门槛 |
|---|---:|
| E | 0 |
| D | 40 |
| C | 120 |
| B | 260 |
| A | 450 |
| S | 700 |
| S+ | 1000 |

经验单调增长，封顶1000；等级按累计经验计算，边界包含门槛。达到等级不等于自动装备高级武器，还需当前职业允许武器类别。

## 二、装备资格一处判断

`canWield(currentClassId,weaponId,character.weaponExp)` 同时检查：

1. 职业在当前阶段允许该武器的 `category`；
2. 角色该武器系累计经验已达到 `requiredRank`。

任一不满足则不能装备。未传进度不得默认按E级放行。战斗合法性还会阻止已装备但后续失去资格的武器攻击（例如测试直接下调经验/临时改变职业）。魔法还要满足W2法术剩余次数、射程及存活等条件。

战斗背包与地图单位旁装备选择菜单都会展示**当前熟练等级、累计经验/下一级门槛、武器需求等级**，不合格项禁用；没有通过反击/预览/敌军动作绕过等级判定的UI途径。

## 三、初始存档与第一关兼容

旧第一关起始装备包括钢剑、钢枪、钢斧、钢弓和长弓，其需求为C，若所有人默认E将改变原有攻击方式。P1选择**显式初始个人培训**，没有给旧装备提供免检后门：

- 剑士岚锋：剑术C（120XP）
- 枪卫槿卫及敌军长枪兵：枪术C（120XP）
- 弓手霜羽及敌军弩手：弓术C（120XP）
- 敌军掠夺者A/B/C：斧术C（120XP）
- 赤旗统领：剑术C（120XP）
- 术士星烬：黑魔法E（0XP），其三种法术均为E级。

其他六项武器技能均从E（0XP）起步。初始累计XP是`CHARACTER_LIBRARY`每个角色显式`startingWeaponExp`，可审查且在新建角色时复制，**不通过“初始装备白名单”绕过资格检查**。未来新角色无需直接赋C，逐步升级应从E开始。

## 四、经验获得规则

| 合法行为 | 基础XP | 当前单武器专精职业+25%（向上取整） |
|---|---:|---:|
| 主动普通物理攻击 | 4 | 5 |
| 主动攻击型黑/白魔法 | 4 | 5 |
| 正式提交物理战技（W2样例） | 6 | 8 |
| 反击（物理或攻击魔法） | 2 | 3 |
| 同次交战中的追击 | 0额外 | 0额外 |
| 非法攻击、法术耗尽、仅预览、仅换装、取消移动、待机 | 0 | 0 |

发起一次合法攻击后，即使未命中，仍给予对应熟练度经验。防守方只有实际完成反击事件才得到一次经验；目标被首击消灭时防守方没有经验。同一场交战发生反击后又追击，仍只获得一次经验结算，不叠加独立第二次奖励。

当前每种实际可用职业仅单主武器类；`CLASS_LIBRARY[classId].weaponCategories[0]`暂作为+25%主专精，之后增加双武器职业时由C1明确主副熟练度加成规则。P1累计进度独立于人物等级经验、职业经验、武器耐久及魔法使用次数。

`src/engine/proficiency.ts`集中存放经验阈值、等级映射、奖赏封顶、职业加成与进度文字；战斗引擎只在**正式完成的交战**记录XP，预览不改变人物、RNG或资源。

## 五、阶段边界与下一步

本阶段**没有实现**：职业认证/切换、职业经验与精通、技能被动或高级战技解锁、完整白魔法治疗、跨关卡自动存档、铁匠铺与经济、属性职业成长率修正。这些留到C1/S1/E1等独立交付。

必须保留W0攻速差≥4追击，W1武器系固有，W2物理普通攻击零耐久、魔法一次交战一次计费。第一关10×8/4v6人数、旧角色等级/HP/基础数值、装备库存、桌面与手机操作保持不变。

### 验收矩阵
- 七系经验互相独立；E/D/C/B/A/S/S+门槛及前一经验的边界值准确，封顶1000。
- 现有角色通过显式起始C经验正确持有原初始钢制武器，新人物默认E且不可直接装备高级武器。
- 低于D禁止细剑/投枪/手斧，低于C禁止钢制与长弓；达到后可装备。
- 当前职业不允许的类别，即使已S+也不允许装备；当前职业与熟练度校验不可缺其一。
- 相同初始成长模板的两名不同角色不共享熟练度引用。
- 普通攻击、魔法、物理战技和反击按一次有效动作奖励；未命中有经验，追击不重复；预测/撤销/耗尽法术零经验。
- UI等级需求、禁用项、经验进度正常；现有测试/CI/桌面移动端浏览器回归均通过。
