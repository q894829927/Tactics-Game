# 战前整备角色详情面板（v0.1.30.3）

这是C2-0战前整备界面的UI完善，不改现有移动、伤害、职业考试或成长规则。

## 布局和内容

桌面：整备面板扩展为左侧出战角色列表、右侧可独立滚动的角色详情区。下方保留职业整备、确认出击与清空进度按钮。手机端纵向排列，队员卡片双列，详情区随整备面板纵向滚动，不出现横向溢出。

角色选择：
- 4名出战角色头像标识（当前是已存在的职业符号，**非外部立绘**）、姓名、职业、人物等级和当前武器。
- 详情包含当前人物等级/经验与当前职业精通经验条；职业精通达到阈值时显示「已精通」。
- 角色属性：默认**当前实际属性**，可切换当前职业的**成长率**。两种模式统一按五行双列显示：HP/移动力、力量/防守、魔力/魔防、速度/幸运、技巧/魅力。HP现值/最大值随当前角色刷新；移动力无单独成长率，显示“—”。
- 战斗能力：当前持有装备+职业补正+已装备精通被动后的实际衍生值，包含物攻、魔攻、耐物、耐魔、命中、回避、攻速、必杀和必避（统一沿用战场角色状态栏的术语，基础属性仍使用防守、魔防）。该数值依照当前战前布阵格的地形防御计算，随后进入战斗时随地形实时变化。
- 随身装备：角色的全部真实库存物品，逐件显示武器名称、威力、命中、射程、武器熟练度需求以及物理武器剩余耐久或法术剩余次数。当前装备明显高亮；不符合当前职业/个人武器等级的物品可查看但不能装备。更换出击武器后主动刷新战斗能力和角色列表装备名称。
- 武器熟练度：七系真实熟练等级与XP进度，并区分当前等级和下一等级目标。
- 已装备精通：C3双槽已实际装备的继承特技及其战斗数值效果，未装备时提供前往职业整备的提示。

## 保留的交互规则

- 选角色只切换详情，不消费回合或更改地图。
- 换装备调用已有`Battle.prepareEquipWeapon`，并由引擎验证可装备条件；已有本机存档随战前操作更新。
- 角色精通特技装备仍在专用职业整备UI进行，不提供第二套装备规则；点击职业整备返回后会同步显示职业变化。
- **不加入**道具转移、升级分配、武器维修、装备出售、手动编辑成长率或虚假的人物立绘。
- 暗蓝/金色风格沿用现有职业整备面板，浏览器分辨率覆盖1920×1080、1366×768与390×844。

## 验收

浏览器端到端新增：默认角色HP和职业数据、正确属性排列、7系熟练度、3件真实装备及其剩余耐久、换钢剑后战斗能力变化、切成长率再返回、切换另一角色装备与属性同步、切回原角色装备选择保留，及整备面板无横向溢出。全量Node/Python及TypeScript/构建流程仍需通过。
