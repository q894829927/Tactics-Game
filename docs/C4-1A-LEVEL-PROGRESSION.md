# C4-1A：关卡数据与章节推进系统

## 已实施

- `src/engine/levels.ts` 定义稳定关卡ID、章节、地形、玩家/敌军部署、胜利目标及解锁依赖。仍限定10×8地图，便于复用全部寻路、动画、UI和AI接口。
- `chapter-1-1` 维持原首关10个部署单位及击败赤旗统领的胜利条件；`chapter-1-2` 是真实可操作的**临时框架验证关**，以不同地形和部署验证切换与解锁，C4-1B必须设计正式战术内容。
- 战前整备选关，首关通关解锁第二关；失败不解锁，重复通关不重复计入完成清单。已完成的旧关可自由重玩，战斗中禁止切换。
- 战役存档追加可选 `selectedLevelId`、`completedLevelIds` 与战后 `levelId`，继续使用原 `wildfield-tactics.campaign.v1` 存储键、个人进度和经济字段；旧档持有骑乘许可则视作首关已过。非法关卡ID、超前解锁、重复清单拒绝；未完成战斗刷新仍回到战前整备。
- 切换关卡重建双方位置、场景树石、地面材质、小地图地形信息；人物经验、职业认证、武器耐久和金钱保留。
- **边界**：C4-1A暂继续现行首关的固定胜利奖励（金币200、名声40、中级凭证1）。正式关卡、首次通关与重玩差异、平衡和经济放到C4-1B/C。

## 验收

`tests/c41Levels.test.mjs` 覆盖原图保持、解锁、失败重试、重复通关、存档迁移与非法数据。CI、浏览器和静态发布需要成功。ECS部署状态单独核实。
