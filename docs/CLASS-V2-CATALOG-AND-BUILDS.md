## 0. 执行摘要与版本边界

- **总计78职业**：保留原策划34种（已实装7初级+2中级）；添加36种常规特色职业；设计8种隐藏职业。层级分布：初级7 / 中级27 / 上级28 / 最上级10 / 传承6。
- **现行真正可操作的只有9职业**（7初级与游剑士、壁垒卫士）；`classes.ts` 内敌军专用步兵/指挥官和 `rider`/`flier` 测试桩不计入78。职业固有、专属战技、真正治疗、骑飞移动、召唤、法阵目前不是现成游戏能力。
- 当前现行的7初级名称：剑士、枪卫、斧斗士、弓手、拳斗士、术士、见习祭司。原 V1.1 表格里写作「剑斗士、枪兵、猎手、术法学徒」的名称**不更名到代码**。
- **冻结九项现行精通**：剑术专注（命中+5）、枪卫架势（耐物+1）、斧刃锐意（必杀+3）、远射专注（命中+8）、身法（回避+5）、魔力护幕（耐魔+1）、祈愿（必避+5）、迅疾（攻速+1）、坚守（耐物+2）。文中这九个以“现行”标注；其他能力均为提案。
- 本图鉴每一行都有武器/资格、当前与成长补正、职业固有、精通、代表行动与弱点。部分特殊能力是新引擎能力，须分阶段落地，不得只靠字段填充伪装可用。
- **表中数字均为平衡起点，不代表实测**；“成长+10%”专指成长率**增加10个百分点**，不乘1.1；未列成长补正一律0。

## 1. 职业体系约束（冻结）

1. **七系武器不可新增第八类别**：剑、枪、斧、弓、拳套、黑魔法、白魔法。混合职业只授予两个以上武器许可，不创造隐含法术权限。
2. **通用追击**：所有合法攻击在攻速差≥4时可追击；剑追击伤害额外×1.2；只有某战技明确写“禁止追击”才例外。普通物理攻击不消耗耐久，战技才消耗；攻击法术按一场交战扣法术次数，追击不额外扣次数。
3. **固有/继承/战技三层隔离**：固有只在当前职业自动生效，不占格；精通获得后可跨职业装备，装备槽限制；主动战技需当前武器许可、熟练度、专用格与资源。职业固有不是精通奖励，武器系固有效果不被职业替代。
4. **数值名词一致**：基础属性“HP、移动力、力量、防守、魔力、魔防、速度、幸运、技巧、魅力”；衍生战斗属性“物攻、魔攻、耐物、耐魔、命中、回避、攻速、必杀、必避、射程”。防守≠耐物，魔防≠耐魔。
5. **不锁死职业树**：任何角色只要满足资格与许可证，都能认证和切换；已认证职业不重复收费；人物基础值、七系熟练度、职业经验、精通、装备实例持久保留。
6. **先物理规则，再表演**：战斗预测须调用纯逻辑，提交一次性扣除资源；动画可以跳过或取消但不影响结果；禁止为预览推进RNG。
7. **维持目前老职业稳定**：已实装九职业的即时补正与继承技能原样不改。新职业不能自动加入 `PLAYER_CLASS_CHOICES`，只经分期上线。

| 层级 | 共有 | 主武器最低等级 | 名声 | 首次认证 | 金币 | 推荐阶段 |

**实现差异**：目前引擎只正式支持“中级”一种凭证和两种中级职业，后续新增的凭证类型、名声门槛、骑乘/飞行许可、任务进度都需要新数据结构和存档迁移。

**多武器判定**：表内 `+` 表示全部门槛；`或` 只表示允许任选其一的主专精，**不免除**后面的许可要求。必须满足当前职业许可与个人武器熟练度，才能装备武器；老角色既有的初级认证不能被收回。

**许可**：骑乘、飞行是从任务/资格获得的认证，并给予单位 Cavalry / Flying 标签；枪克骑乘威力×2、弓克飞行威力×3仅针对有效武器威力。骑飞特殊移动规则是新功能，允许跨低障碍但不得跨越封闭障碍或停在占用格；高差、路障、反召唤等需要独立规则。

### 3.6 图鉴字段解释与主动能力可用性

- **每职业三件套**：固有特技自动生效（随当前职业）；精通技能解锁后占继承被动槽（跨职业）；标志性招式属于该职业独占的职业行动，当前职业认证后才出现且占一次普通行动，**不占通用主动战技槽**。
- **通用七系基础战技**沿用原V1.1设计：剑「疾刃」D/耐久3、枪「截步刺」D/耐久4、斧「裂甲击」D/耐久4且禁止追击、弓「定点射」D/耐久3且禁止追击、拳套「虚步击」D/耐久3、黑「蚀弱咒」C/法术次数2、白「护壁祝祷」D/法术次数2。对应初级职业不代表一开始在E级即可使用这些战技，仍须学会并满足武器等级。
- **职业专属招式资格**默认由当前职业认证 + 当前装备合法 + 熟练度达到该职业门槛决定。若招式与泛用同名（例如剑士使用疾刃），只提供同一动作，不重复造两个按钮。待S1/C4实装时将各专属招式映射成稳定的 skill ID。
- **默认射程**：敌方单体攻击使用当前武器射程；治疗/增益使用对应白魔法法术实际射程；铺设陷阱、旗帜、法阵、路障默认仅可在距离1以内的可用空格；有效范围不得由职业叙述覆盖武器/法术合法性。
- **费用口径**：表中“耗法术次数2”表示该次主动行为总计扣2次，不是基础1再追加2；若当前装备次数不足则按钮禁用并注明原因；同时耗物理耐久+法术次数的复合招式必须两种资源都足够。
- **招式中的状态词**必须采用下一章词典；没有写额外持续时间的暂时效果统一到该次交战或本轮结束；“首次”默认指每个角色每轮一次。特殊位置效果必须在实际地图生成可见标记。

## 4. 通用效果规则：能力不靠“文字想象”

### 4.1 单位、移动和出手
- 每单位每轮默认最多执行**一次已确认行动**。移动中可以撤回试移动；攻击、治疗、布置、召唤或待机一经确认即锁定，本次行动不因后续特技而恢复。
- **攻击后再移动**属于行动内的位移子阶段，仅能在合法空格进行、每轮上限1次；不得穿越敌军、跳过碰撞、抢占友军格，也不能额外攻击。动画同步用合法移动路径逐格表现。
- **体格/重量/攻速**采用当前引擎的计算，不另引入“敏捷点数”。减移动力与改变寻路成本都通过合法地图层计算，目标移动力下限1；免疫地形不可被减成本攻破。
- **位移控制**优先级：当前强制位移合法性→目标类型抵抗→地图占格与障碍→移动路径→一次性提交。除特定首领外，不允许拉拽与推挤强制移动大型单位。

### 4.2 通用状态词典
| 状态 | 统一规则 | 允许叠加 |
|---|---|---|
| 灼烧 | 行动开始受2点固定伤害，持续1轮；最多降至1HP（首版） | 否；重复仅刷新持续 |
| 缓足 | 移动力-1一轮，最低1 | 否；重复仅刷新 |
| 弱甲 | 耐物-2一轮 | 否；同组取最大绝对值 |
| 弱咒 | 耐魔-2一轮 | 否；同组取最大绝对值 |
| 标记 | 被指定攻击的命中+5一轮，不能跨多标记叠加 | 否 |
| 护盾 | 先抵消伤害；单次最大5HP，战斗中显示剩余量 | 可刷新，不相加 |
| 虚弱 | 下一轮力量/魔力效果伤害-2且不能再次触发保命 | 否 |
| 潮势 | 1层/受伤事件，至多2层，换轮清除 | 按层计，封顶2 |
| 旗阵 | 只计算当前部署者的有效旗帜，多个取最优单项效果 | 不能同类相加 |
| 法阵 | 每名施放者场上至多一个；敌我可见；仅空格部署 | 区域重叠只生效最强一个 |

### 4.3 触发顺序与边界
1. 验证当前职业、装备、熟练度、目标距离、路线、行动资源和技能次数。
2. 读取**不可变交战上下文**，应用地形、职业固有和已装备被动；生成纯预测，标注不确定命中、反击和追击。
3. 真正交战中按“主动首击→合法反击→合法追击”处理；仅首击的战技特效触发一次，追击是普通追加攻击事件。
4. 结算命中、伤害、护盾、异常状态，再结算死亡/阻断、反制、有限联携和一次性资源扣除。
5. 后置撤退/引导/召唤物位置改变在独立子阶段完成；不生成新的完整行动、不允许无限触发。
6. 结算人物经验、武器经验、职业经验；一次交易至多一份职业XP和武器XP（按现有规则）。

### 4.4 叠加及经济上限（V2.0平衡建议）
- 已装继承特技合计：命中增益上限+20，回避+20，必杀+10，直接伤害+4；同名同源效果不叠。对已有现行精通“剑术专注+5”“远射专注+8”等保留原数据，不削弱它们本身，只规范将来与其他新技能的合成。
- 单次受到的额外减伤来自**非地形、防守基础值**的累计上限3；同名护盾不累加；多旗帜、法阵、歌谣按相同效果组选优。
- 同一行动中队友援助最多触发一次，禁止援助再触发援助；反击触发奖励不再延伸新反击。召唤物不能授予额外职业经验或刷击杀奖励。
- 物理战技耗耐久（通常3–7）；白/黑法术耗对应法术次数（常规1，强力2–3）；献祭类额外消耗当前HP但不得把施法者HP降到0；部署类占用一次已确认行动。
- 无关卡限制的“时间倒流、真正额外完整回合、无条件复活、全屏无差别清场”**不作为常规职业能力**；保护首领机制、地图通行与随机确定性。

## 5. 继承、流派与玩家构筑

### 5.1 三层能力与槽位
| 系统层级 | 获得/生效 | 当前实现 | 未来规则 |
|---|---|---|---|
| 当前职业固有 | 职业切换时自动替换，离职即失效 | `innateAbilityIds`尚未接入完整战斗 | 每职业1个核心固有，部分可拥有职业行动 |
| 继承被动 | 当前职业达到精通后永久解锁；必须手动装备 | 2槽已实现 | Lv10可考虑第3槽，先经平衡验收 |
| 主动战技 | 熟练度与职业许可双重校验，配备战技槽 | 尚未正式接入玩家交互 | 初始1槽，Lv10扩至2槽（未来提案） |
| 武器固有 | 由当前装备自动决定 | 七系固有效果已实现 | 不占技能槽，不可因转职绕过 |

**精通阈值**：现行初级80、中级120不变；提案上级160、最上级200、传承240。现行职业经验主动攻击+10、实际反击+5、待机+4保持不变；真正治疗和布阵将来新增XP需基于有效值且每行动最多领取一次，禁止靠满血反复刷。

### 5.2 职业流派模块（不额外膨胀职业数）
| 当前职业 | 流派A | 流派B | 权衡 |
|---|---|---|---|
| 精锐射手 | 狙击：原地远距命中+5 | 压制：命中后缓足1次/轮 | 二选一 |
| 影步剑客 | 迅击：先手命中+5 | 影退：后置退位范围+1但不穿障 | 无法同时启用 |
| 符阵师 | 灼纹：伤害阵 | 封域：缓足阵 | 一个施法者只维护一阵 |
| 盾誓骑士 | 前盾：自身减伤 | 护约：邻友护卫 | 本回合只能一种架势 |
| 祷歌师 | 战歌：攻 | 守歌：防 | 行歌单独占第二备选但同一回合只用一首 |
| 空骑枪手 | 冲锋型：攻击命中加成 | 侦察型：扩大视野 | 同一场只能选一种 |

职业流派是未来“职业额外配置”而非继承被动；同一战前阶段配置，战中不可临时换流派。不强制每个职业都有分支，优先用有实际二选一价值的职业做试点。

## 6. 地形、敌军AI与可反制关系

| 新玩法 | 玩家收益 | 敌人如何反制 | 实施基础 |
|---|---|---|---|
| 骑兵冲锋 | 长距离建立优势 | 枪系特效与窄路、阻挡 | 骑乘寻路/标签、可停格 |
| 飞行机动 | 跨低障碍绕后 | 弓×3武器威力特效 | Flying标签/地形过滤 |
| 陷阱与法阵 | 改变敌人路线 | 显示危险范围、可绕开或清除 | 临时地形覆盖层 |
| 旗帜/路障 | 守路、拒敌 | 敌人可攻击旗帜/路障 | 中立可受击实体 |
| 拉拽/推挤 | 破坏敌人阵型 | 重型免疫、障碍阻隔 | 受控合法位移 |
| 辅助歌谣 | 强化一个关键行动 | 切断歌者/规避强化目标 | 状态系统与AI评价 |
| 召唤与野兽 | 临时堵位或侦察 | 远程击破或绕行 | 召唤单位AI、生命周期 |
| 献祭与低血量 | 强化爆发与治疗 | 压制施法者的生命安全 | 生命成本原子结算 |

**敌军规则**：新职业效果对AI与玩家同原则，不能只有玩家获益。AI需要计算负面状态、行动阻挡、护卫、召唤的威胁分数与预计收益；行为一致性与可解释性优先于复杂搜索。

## 7. 4张新机制验收地图

### 桥口防线

- 关卡：一条仅2格宽的桥，守卫与远程敌军；验证盾誓护卫、绳索拉拽、法阵与工事合法性。
- 验收：同一地图至少可由正面破阵、绕后射击、阵地保护三种打法通关。

### 双翼崖谷

- 关卡：树林与可跨越低障碍、遮蔽区，加入1骑兵与1飞兵；验证移动模式与枪/弓克制。
- 验收：飞兵不能穿越禁飞格，弓特效倍率正确，骑兵不能忽视合法格限制。

### 暗灯遗迹

- 关卡：可交互机关、可破坏的旗帜及两处守卫法阵；验证支援与陷阱反制。
- 验收：陷阱不能叠出无限伤害，首领AI会选择可行绕路。

### 残血撤退

- 关卡：受损队伍遭精锐夹击，提供治疗与牺牲类战技、召唤堵路机会。
- 验收：血量消耗不致自杀，濒死保护不循环，治疗不刷经验。

战斗效果单独注册 `EffectDefinition`（触发时机、筛选器、目标、资源、持续、叠加组、次数上限），不要在 `classes.ts` 按职业写特殊分支。`ClassBlueprintV2` 为建议接口，并不代表现有 TypeScript 已具备这些字段。

### 8.2 CI 与存档验收清单
- 职业ID不可冲突，职业总量按开放标签维护；未开放职业不能在真实转职界面出现可操作入口。
- 认证原子性：资格不足、法术资源不足、技能未解锁、道具不足均无副作用；考试消耗一次，旧认证反复切换不花钱。
- 武器熟练度、职业经验与角色等级独立；旧档九职业/旧精通ID保持；新增字段缺失按安全默认迁移，不丢人物属性、装备耐久。
- 决定性：相同输入与种子得到相同结果；预览纯读取；追击合法统一≥4，战技明确例外；普通物理不耗耐久。
- 路径：己方可穿越队友但不能占终点；敌方同理；飞行与骑乘各自过滤地形/敌方单位；动画始终沿合法路线逐格移动。
- 性能：一局上限有限的召唤/旗/法阵实体；攻击预览不递归推导无限联携；移动端与桌面端所有按钮都能关闭与撤销。
- 部署：按 AGENTS / VERSIONING 每次代码提交同步 `src/version.ts` 与 `CHANGELOG.md`，等待 CI、浏览器验收和网站发布**全部完成**才报告“已完成”。

## 9. 当前需确认的策划决议（默认建议已填）

1. **总名录先按78种冻结为候选**，不等于版本2.0就实装78种；每期开放职业加 `releaseStage` 标签。
2. **武器七系不扩张**，创造性靠混搭、能力触发、地形和职业联携。
3. **自由转职不等于无限无成本**：基础免费，中级及以上第一次认证消耗已明确资源；隐藏职业另需任务。
4. **新增角色职业固有**只在当前职业生效，已解锁的精通永久继承但受槽位上限限制。
5. **高等级职业更强但不全能**：强属性加成伴随资源、地形、射程或资格限制；任何高级控制都有反制。
6. **先 S1/C4，后 C5/C6/C7**；优先验证影步、盾誓、祷歌、符阵、绳索五项差异最大的能力，再扩大数量。
