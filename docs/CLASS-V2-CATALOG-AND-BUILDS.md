## 0. 执行摘要与版本边界

- **总计78职业**：保留原策划34种（已实装7初级+2中级）；添加36种常规特色职业；设计8种隐藏职业。层级分布：初级7 / 中级27 / 上级28 / 最上级10 / 传承6。
- **现行真正可操作的只有9职业**（7初级与游剑士、壁垒卫士）；`classes.ts` 内敌军专用步兵/指挥官和 `rider`/`flier` 测试桩不计入78。职业固有、专属战技、真正治疗、骑飞移动、召唤、法阵目前不是现成游戏能力。
- 当前现行的7初级名称：剑士、枪卫、斧斗士、弓手、拳斗士、术士、见习祭司。原 V1.1 表格里写作「剑斗士、枪兵、猎手、术法学徒」的名称**不更名到代码**。
- **冻结九项现行精通**：剑术专注（命中+5）、枪卫架势（耐物+1）、斧刃锐意（必杀+3）、远射专注（命中+8）、身法（回避+5）、魔力护幕（耐魔+1）、祈愿（必避+5）、迅疾（攻速+1）、坚守（耐物+2）。文中这九个以“现行”标注；其他能力均为提案。
- 本图鉴每一行都有武器/资格、当前与成长补正、职业固有、精通、代表行动与弱点。部分特殊能力是新引擎能力，须分阶段落地，不得只靠字段填充伪装可用。
- **表中数字均为平衡起点，不代表实测**；“成长+10%”专指成长率**增加10个百分点**，不乘1.1；未列成长补正一律0。
- **本次收敛重点**：78种保留为候选库，不承诺全部成为独立开放职业；用战场决策区分职业，补齐招式收益、继承触发条件、状态时点和研发依赖。九项现行精通、现行职业补正、待机职业XP均保持冻结。

### 0.1 职业进入开发的最低标准

每个候选职业须补齐一张验收卡：**核心职责、典型一回合操作、占用一个队伍名额的理由、可执行的反制、收益与代价、依赖系统、优于/劣于替代职业的局面**。名称、背景或触发条件换词不能单独证明职业差异。

- 从输出、生存、机动、支援、资源效率五个维度比较同层职业；每项强收益须有战斗内代价。考试昂贵、任务难只影响获得时间，不能代替实战弱点。
- 在相同角色基础属性、可用装备、精通槽位及关卡目标下比较。既测试无继承状态，也测试常见继承组合，避免把角色或装备差异误当职业特色。
- 若两个候选在多数验收场景中的最佳行动相同，先保留一个上线，另一个进入流派试验；保留候选ID，不删除现行职业或强制更名。
- “慢”“脆”“耗费高”等弱点必须对应属性、行动条件、资源或地图规则；未落成规则的描述不得用作平衡依据。

## 1. 职业体系约束（冻结）

1. **七系武器不可新增第八类别**：剑、枪、斧、弓、拳套、黑魔法、白魔法。混合职业只授予两个以上武器许可，不创造隐含法术权限。
2. **通用追击**：所有合法攻击在攻速差≥4时可追击；剑追击伤害额外×1.2；只有某战技明确写“禁止追击”才例外。普通物理攻击不消耗耐久，战技才消耗；攻击法术按一场交战扣法术次数，追击不额外扣次数。
3. **固有/继承/战技三层隔离**：固有只在当前职业自动生效，不占格；精通获得后可跨职业装备，装备槽限制；通用主动战技需当前武器许可、熟练度、专用格与资源；唯一职业独占入口的例外见3.6。职业固有不是精通奖励，武器系固有效果不被职业替代。
4. **数值名词一致**：基础属性“HP、移动力、力量、防守、魔力、魔防、速度、幸运、技巧、魅力”；衍生战斗属性“物攻、魔攻、耐物、耐魔、命中、回避、攻速、必杀、必避、射程”。防守≠耐物，魔防≠耐魔。
5. **不锁死职业树**：任何角色只要满足资格与许可证，都能认证和切换；已认证职业不重复收费；人物基础值、七系熟练度、职业经验、精通、装备实例持久保留。
6. **先物理规则，再表演**：战斗预测须调用纯逻辑，提交一次性扣除资源；动画可以跳过或取消但不影响结果；禁止为预览推进RNG。
7. **维持目前老职业稳定**：已实装九职业的即时补正与继承技能原样不改。新职业不能自动加入 `PLAYER_CLASS_CHOICES`，只经分期上线。

**实现差异**：目前引擎只正式支持“中级”一种凭证和两种中级职业，后续新增的凭证类型、名声门槛、骑乘/飞行许可、任务进度都需要新数据结构和存档迁移。

**多武器判定**：表内 `+` 表示全部门槛；`或` 只表示允许任选其一的主专精，**不免除**后面的许可要求。必须满足当前职业许可与个人武器熟练度，才能装备武器；老角色既有的初级认证不能被收回。

**许可**：骑乘、飞行是从任务/资格获得的永久认证；只有当前职业实际采用相应移动模式时，单位才获得 Cavalry / Flying 标签，切回步行职业不保留该标签。枪克骑乘威力×2、弓克飞行威力×3仅针对有效武器威力。飞行允许跨低障碍，骑乘仍按地面通行与骑乘地形代价寻路；二者都不得跨封闭障碍或停在占用格。高差、路障、反召唤等需要独立规则。

### 3.6 图鉴字段解释与主动能力可用性

- **每职业三件套**：固有特技自动生效（随当前职业）；精通技能解锁后占继承被动槽（跨职业）；职业独占招式需当前职业认证，占一次普通行动，**不占通用主动战技槽**。职业独占入口最多1个；火/护/缚阵等是同一入口的互斥模式，不同时提供多个免费行动。
- **通用七系基础战技**沿用原V1.1设计：剑「疾刃」D/耐久3、枪「截步刺」D/耐久4、斧「裂甲击」D/耐久4且禁止追击、弓「定点射」D/耐久3且禁止追击、拳套「虚步击」D/耐久3、黑「蚀弱咒」C/法术次数2、白「护壁祝祷」D/法术次数2。对应初级职业不代表一开始在E级即可使用这些战技，仍须学会并满足武器等级。
- **职业专属招式资格**默认由当前职业认证 + 当前装备合法 + 熟练度达到该职业门槛决定。初级表的七系同名招式只是代表行动，归类为通用战技，仍须学习、满足D/C门槛并占通用槽，**不能获得免费专属入口**。动作以稳定 skill ID 去重，不以显示名称判断；切职业后通用动作保留学习记录，独占动作立即失效。
- **默认射程**：敌方单体攻击使用当前武器射程；治疗/增益使用对应白魔法法术实际射程；铺设陷阱、旗帜、法阵、路障默认仅可在距离1以内的可用空格；有效范围不得由职业叙述覆盖武器/法术合法性。
- **费用口径**：表中“耗法术次数2”表示主动行为总计扣2次，不是基础1再追加2；单系动作从选定的合法武器/法术实例扣除。复合动作须显式指定物理装备实例与法术ID，各自满足当前职业权限、熟练度、持有和剩余资源；不能因只检查当前装备而漏校验另一种资源。所有成本一次提交，不足则禁用并注明原因。
- **招式中的状态词**必须采用下一章词典；首击修正仅作用该次首击，其他临时效果须登记明确的到期事件。“首次”默认每个单位每轮一次，轮次从我方阶段开始到敌方阶段结束。没有精确时点的候选不得进入实现。特殊位置效果须在地图生成可见标记。

### 3.7.1 盾誓骑士护卫协议（P0，未来实现）

- **触发窗口**：攻击者声明一次合法的敌对单体直接交战后、命中与暴击判定前选择承伤者；必须先通过攻击者行动、目标和资源资格校验。护卫者须存活、与**原始目标正交相邻**（上下左右，不含对角）、同阵营、具有当前职业「守约」、尚未消耗本轮护卫，且攻击者对护卫者的射程及视线同样合法。范围伤害、治疗、持续伤害、连锁次级伤害均不触发护卫。
- **已行动仍可护卫**：护卫是每轮最多一次的自动反应，不占护卫者正常行动，也不要求护卫者尚未行动；已经攻击、待机或移动过的护卫者，只要仍符合位置/状态条件，就能自动护卫。处于无法反应状态的单位不能护卫。护卫反应额度在每个全局轮次开始（玩家行动阶段开始）重置，同轮玩家阶段与敌方阶段共用一次额度；双方阵营适用相同规则。
- **多护卫与消耗**：多个符合条件的护卫者，首版按稳定角色ID字典序选择一个（不能依赖DOM、数组遍历偶然顺序或随机数）；必须在预测中标明。正式确认并成功提交交战后即消耗这一次护卫额度，即使首击**未命中**也已消耗；非法指令、仅预览或取消不消耗。其他候选本次交战不再串联护卫。
- **整场锁定承伤者**：首击、合法反击和合法追击均以护卫后的参战双方为准。按护卫者自身属性、地形、装备计算命中、耐物/耐魔、护盾、减伤与合法反击射程；不瞬移、不换位。若护卫者在交战途中死亡，本次交战结束，不把剩余攻击转回原目标。护卫本身不生成额外攻击或额外职业经验。
- **可观察性**：预测UI必须同时展示原目标、实际承伤者、护卫额度及两者位置；结算事件记录 `GuardRedirected`、`GuardChargeConsumed`，与后续攻击事件使用同一稳定ID。任一条件不成立时维持原目标；不能因为敌军/玩家客户端不同而改变选择规则。

### 3.7.2 链枪与缓足：先读旧状态、后写新状态（P1）

- 对「链枪」和「索缚」统一在**交战首击执行前**冻结目标是否已经带有有效「缓足」：如果已有，链枪首击伤害+2；若没有，这一次链枪即使命中并新施缓足，也**不能立刻获得+2伤害**。额外伤害只算主动首击，不附加到反击、追击或同次交战的后续攻击事件。
- 链枪命中且目标存活时，在实际伤害和护盾结算后施加或刷新一份缓足；索缚在满足其每轮一次的前提下，若目标原本无缓足可尝试施加。两者同击触发只生成/刷新**一个**缓足实例，移动力-1（最低1），不叠层、不回溯改变当前已走路径。
- 链枪的+2属于伤害修正（斧保底/必杀等通用次序不变）；攻击未命中不施加缓足，但合法确认的耐久4照常消耗。目标已缓足且首击未命中，也不能获得实际额外伤害。反复刷新延续到期时间但不会累加移动惩罚。
- 预测同时展示「攻击前已有缓足：是/否」「本次命中后预计缓足状态」「首击是否享受+2」，命中与状态抗性按概率展示，不为预览掷随机数。

### 3.7.3 旗阵统领：四人队伍的可执行站位（P1）

- 「阵旗」只将**存活、非召唤、同队的出击单位**算作阵型人数；要求旗阵统领自身和至少**两名其他友军**分别在正交相邻四格内（允许左/右、前/后任意组合，不要求直线），对角不算，召唤物、部署旗帜及死亡友军不算。
- 阵型形成后，统领本人以及其正交邻接的存活友军获得耐物+1；超过两名邻友不提高数值。移动或死亡使有效人数跌到两名以下时**立即失效**，恢复站位后可重新生效；敌我均使用实际占格和相同判断，预览目的地时按拟议占格纯计算，取消移动不改变实际阵型。
- 「结阵」是独立主动职业行动：统领**本轮未确认主动移动**、仍具备合法枪武器、至少有一名有效正交邻接友军时可用；确认后消耗统领完整行动及该枪实例耐久4，为相邻友军施加持续一轮的耐物+2，不要求「阵旗」已激活。若同时受阵旗+1，遵守§4.4额外防护预算上限3；不增加邻友行动次数，不给统领本人「结阵」+2。
- 以现有4人小队为基础测试四种队形：统领+1邻友（阵旗不生效）、统领+2邻友（生效）、统领+3邻友（不叠加）、任一邻友离开或倒地（即时失效）。验收必须比较集中站位带来的群攻风险和绕路成本；若阵型在典型10×8地图中极难维持，优先调整关卡障碍/地形或改为流派方案，不暗中放宽邻接规则。

## 4. 通用效果规则：能力不靠“文字想象”

### 4.1 单位、移动和出手
- 每单位每轮默认最多执行**一次已确认行动**。移动中可以撤回试移动；攻击、治疗、布置、召唤或待机一经确认即锁定，本次行动不因后续特技而恢复。
- **攻击后再移动**属于行动内的位移子阶段，仅能在合法空格进行、每轮上限1次；不得穿越敌军、跳过碰撞、抢占友军格，也不能额外攻击。动画同步用合法移动路径逐格表现。
- **体格/重量/攻速**采用当前引擎的计算，不另引入“敏捷点数”。减移动力与改变寻路成本都通过合法地图层计算，目标移动力下限1；免疫地形不可被减成本攻破。
- **位移控制**优先级：当前强制位移合法性→目标类型抵抗→地图占格与障碍→移动路径→一次性提交。除特定首领外，不允许拉拽与推挤强制移动大型单位。

### 4.2 通用状态词典
| 状态 | 统一规则 | 允许叠加 |
|---|---|---|
| 灼烧 | 下次所属阵营行动阶段开始受2点固定伤害，阶段结束移除；最多降至1HP（首版） | 否；重复仅刷新，不追加当期伤害 |
| 缓足 | 移动力-1一轮，最低1 | 否；重复仅刷新 |
| 弱甲 | 耐物-2一轮 | 否；同组取最大绝对值 |
| 弱咒 | 耐魔-2一轮 | 否；同组取最大绝对值 |
| 标记 | 被指定攻击的命中+5一轮，不能跨多标记叠加 | 否 |
| 护盾 | 先抵消伤害；单次最大5HP，战斗中显示剩余量 | 可刷新，不相加 |
| 虚弱 | 下一轮力量/魔力效果伤害-2且不能再次触发保命 | 否 |
| 潮势 | 受到直接攻击实际HP伤害时+1，每次交战最多1层、总上限2；持续至持有者下次行动阶段结束或被回浪消耗 | 反击/追击不能在同一交战重复叠层；持续伤害、自损、护盾完全吸收不计 |
| 旗阵 | 只计算当前部署者的有效旗帜，多个取最优单项效果 | 不能同类相加 |
| 法阵 | 每名施放者场上至多一个；敌我可见；仅空格部署 | 区域重叠只生效最强一个 |

**时间术语与生命周期：**

- 行动阶段指一方的整个阶段，不是某个单位点击行动按钮。“自身下次行动阶段”指创建状态之后所属阵营下一次开始的阶段，跳过单位或提前结束回合同样触发到期。
- 普通“一轮”状态统一在受影响单位的**下次所属阵营行动阶段结束**时到期；灼烧在该阶段开始扣血一次，再于阶段结束移除。增益、减益均显示具体到期阶段，不能依赖动画或待机按钮计时。
- “下一次命中/攻击/承伤”修正只有匹配事件可消耗，并设置上述到期兜底；单次攻击指一次首击、反击或追击事件，整次交战包含这些事件。“下一次主动首击”不会被反击消费。
- “下一次移动”修正从路径预览起就参与计算，在实际行动确认后消费；取消移动不消费。警戒对进入者的本次剩余预算生效，缓足影响完整移动预算，二者分别显示且不得把单位推入非法格。
- 持续2轮的部署物在部署者第2个后续所属阵营行动阶段结束时移除；新部署需先在预测中显示将替换的旧实体。部署者死亡时移除其实体，不能在关卡结束后残留。
- 可延长减益首版仅包括缓足、弱甲、弱咒；最多从目标下次行动阶段结束延至再下次阶段结束，同一实例仅延长一次。时砂封存与咒法强化不能连续接力延长；灼烧、警戒即时拦截、自损代价、护盾和召唤物寿命不延长。
- “本轮未移动”统一指未确认主动移动；撤回试移动不计，受迫位移不计。警戒单位若被迫位移，警戒立即解除；“下次回合”均指上述所属阵营阶段，不使用含混的全局轮号。
- 持续效果倒计时、可见敌人的装备与状态、护盾余量、已知威胁范围是基础UI，不需职业解锁。星相占师可额外显示按当前AI计算的目标意向，注明其依据并在战局改变后重算，不承诺敌人一定执行。
- 状态抗性首版指独立抵抗可抵抗减益的概率，+20%表示增加20个百分点；命中后才判定抵抗，使用同一战斗RNG。预览显示成功概率而不掷骰；弱甲、弱咒、缓足、灼烧可抵抗，自损代价、标记、强制位移不由此概率豁免。

### 4.3 触发顺序与边界（P0：唯一提交顺序）

1. **验证行动资格（只读）**：检查阶段、阵营、职业、装备、技能/熟练度、目标、原始射程/视线、地图路径、行动状态、资源与法术次数；任一不合法立即拒绝且零副作用。
2. **冻结交战上下文（只读）**：确定攻击者、原始目标，依§3.7.1筛选护卫并锁定唯一实际承伤者，读取双方装备/地形/固有/继承与攻击前状态；反击与追击资格按实际参战者评估。护卫不改变原始攻击者已经合法声明的目标位置。
3. **生成预测（只读）**：展示命中、伤害、护卫、反击、追击、状态成功概率、资源与撤退合法格；预览不掷RNG、不改变护卫额度、阵型、状态倒计时或行动状态。取消预览直接返回。
4. **正式确认并原子提交成本**：重新校验本次上下文仍合法，冻结动作和目标，然后**一次性**锁定行动、支付技能/物理耐久/法术次数/HP成本，记录护卫反应消费。费用不足则整笔失败；合法攻击未命中也消耗费用，追击不得重复扣费。
5. **逐击交战结算**：按「主动首击→仍合法的反击→仍合法的追击」依次执行。每击依次判定命中及状态抗性所需随机数（严格按事件触发次序）、伤害与武器系特效（含斧保底/必杀/剑追击）、额外减伤（最低0）、护盾吸收、实际HP损失、一次性保命、死亡或阻断，最后对仍存活目标施加首击限定的异常状态。链枪的既有缓足判定使用第2步冻结值，不使用本击刚施加的缓足；潮势只根据实际直接HP损失登记。本步若实际承伤者死亡即终止交战。
6. **后置效果结算**：交战存活及合法性再次校验后，才执行攻击后退位、友军引导、有限联携或部署物移动等位移子阶段；每行动最多一次，不额外生成完整攻击行动。需玩家选择的位置若无合法目标则拒绝该子效果，不回滚已提交的合法交战；预测应提前列出这一风险。
7. **最终归档与表现**：提交战斗事件、人物/武器/职业经验（保持现行单次交战XP规则）、胜败检查与存档，再播放动画；动画取消或跳过不影响一次性结算。预测与执行应共享资格、目标替换和伤害/状态逻辑，不各写一套。

**边界**：以上为未来统一流程的设计规范，不声称当前引擎已实现完整状态/护卫/战技系统；AI与玩家都从相同规则生成合法行动。无效治疗、预览或取消不得消耗资源/刷经验；状态时间以§4.2的阵营行动阶段事件为准，而非动画帧数。

### 4.4 叠加及经济上限（V2.0平衡建议）
- 已装继承特技合计：命中增益上限+20，回避+20，必杀+10，直接伤害+4；同名同源效果不叠。对已有现行精通“剑术专注+5”“远射专注+8”等保留原数据，不削弱它们本身，只规范将来与其他新技能的合成。
- 额外防护预算：继承提供的耐物/耐魔加成与职业/技能提供的固定减伤，按物理、魔法分别合计最多3；不含人物基础值、当前职业基础属性补正、地形或护盾。先计耐物/耐魔加成，再按剩余额度计固定减伤，避免同一加成重复算入。现行枪卫架势+坚守仍完整提供耐物+3；新技能不得再叠固定物理减伤突破预算。同名护盾不累加；多旗帜、法阵、歌谣按相同效果组选优。此为未来组合上限，不修改现行九项技能数据。
- 同一行动中队友援助最多触发一次，禁止援助再触发援助；反击触发奖励不再延伸新反击。召唤物不能授予额外职业经验或刷击杀奖励。
- 物理战技耗耐久（通常3–7）；白/黑法术耗对应法术次数（常规1，强力2–3）；献祭类额外消耗当前HP但不得把施法者HP降到0；部署类占用一次已确认行动。
- 无关卡限制的“时间倒流、真正额外完整回合、无条件复活、全屏无差别清场”**不作为常规职业能力**；保护首领机制、地图通行与随机确定性。

## 5. 继承、流派与玩家构筑

### 5.1 三层能力与槽位
| 系统层级 | 获得/生效 | 当前实现 | 未来规则 |
|---|---|---|---|
| 当前职业固有 | 职业切换时自动替换，离职即失效 | `innateAbilityIds`尚未接入完整战斗 | 每职业1个核心固有，部分可拥有职业行动 |
| 继承被动 | 当前职业达到精通后永久解锁；必须手动装备 | 2槽已实现 | Lv10可考虑第3槽，先经平衡验收 |
| 主动战技 | 熟练度与职业许可双重校验，配备战技槽 | 尚未正式接入玩家交互 | 初始1槽，Lv10扩至2槽（未来提案） |
| 武器固有 | 由当前装备自动决定 | 七系固有效果已实现 | 不占技能槽，不可因转职绕过 |

**精通阈值**：现行初级80、中级120不变；提案上级160、最上级200、传承240。现行职业经验主动攻击+10、实际反击+5、待机+4保持不变；真正治疗和布阵将来新增XP需基于有效值且每行动最多领取一次，禁止靠满血反复刷。

### 5.2 职业流派模块（不额外膨胀职业数）
| 当前职业 | 流派A | 流派B | 权衡 |
|---|---|---|---|
| 精锐射手 | 狙击：原地远距命中+5 | 压制：命中后缓足1次/轮 | 二选一 |
| 影步剑客 | 迅击：先手命中+5 | 影退：后置退位范围+1但不穿障 | 无法同时启用 |
| 符阵师 | 灼纹：伤害阵 | 封域：缓足阵 | 一个施法者只维护一阵 |
| 盾誓骑士 | 前盾：自身减伤 | 护约：邻友护卫 | 本回合只能一种架势 |
| 祷歌师 | 战阵流：战歌强化额外+1伤害（总+2） | 行军流：行歌强化额外+1移动力（总+2） | 战前二选一；三首歌在两流派中始终可选，不占通用战技槽；守歌基础效果不变 |
| 空骑枪手 | 冲锋型：攻击命中加成 | 侦察型：扩大视野 | 同一场只能选一种 |

职业流派是未来“职业额外配置”而非继承被动；同一战前阶段配置，战中不可临时换流派。不强制每个职业都有分支，优先用有实际二选一价值的职业做试点。

**祷歌师三曲协议（P1，未来实现）**：

- 「战歌」「守歌」「行歌」是**同一职业独占行动入口**的三种互斥模式，随祷歌师职业开放，无须在战前从三首中预选两首；不消耗通用主动战技槽，也不赋予额外行动。每次选定一名合法友军目标（可选自身，必须在所用白魔法实际射程内），确认后统一消耗白法术次数**合计2次**，并结束歌者本轮行动。无合法可用法术资源时禁用全部曲调。
- 基础效果分别为：**战歌**令目标下一次主动首击最终固定伤害+1；**守歌**令目标下一次受到的单次直接攻击固定伤害-1（最低0）；**行歌**令目标下一次已确认主动移动的移动预算+1。不能重新攻击、再行动或超过地图合法路径；无命中/承伤/移动事件则在目标下次所属阵营行动阶段结束时到期。
- 战前只选择**一个流派增幅**：「战阵流」把战歌伤害由+1改为+2；「行军流」把行歌移动预算由+1改为+2。两种流派都仍可使用三首曲调，守歌始终为-1，歌者同一时刻只维持一首曲调的一个有效实例；换歌时旧歌效提前结束，目标有来自多个歌者的同组歌效仅取最强，不叠加。
- 结算应先确认目标与施法资源，再支付行动与次数；选择曲调不立即消费、取消不扣费。增加战歌的固定伤害不能额外触发新的追击，守歌适用§4.4防护预算，行歌只改变路线预算并从路径预览起生效，实际确认后消费；歌曲被驱散时立即失效。界面同时显示当前流派、三曲效果、剩余次数及已维持的歌曲。
- 以**不改变敌方/友方基本攻击次数**为硬约束。使用一名歌者等于放弃其当回合本可发起的攻击/治疗机会，应在测试中对比「唱歌后队伍总收益」与「歌者直接行动总收益」。

### 5.2.1 继承设计与跨职业适用性

- 九项现行精通保持原效果、原ID、原数值：剑术专注与远射专注都是不限武器的命中加成，不能因为名称误加剑/弓限制。两者都已解锁时，同占一槽的+8优于+5，是已知的现行取舍；本次不暗改。后续是否调整旧奖励须另立平衡方案。
- 新继承优先改变行动条件或协作方式，避免再扩充无条件“命中+N”梯度。每项需标注触发者、受益者、有效动作、叠加组、消耗与到期，至少给出两个可使用它的当前职业。
- 条件依赖不等于授予能力：精线/铁线不会授予召唤，阵识不会授予法阵，虚步不会授予闪移。无合法触发方式时，整备界面标注“当前配置无法触发”；不得暗增武器、法术或行动权限。
- 精线/铁线明确为召唤专用，可供傀儡师、铁傀御使等具备召唤的职业使用；虚步属于机动专用，若开放期只有虚空行者能触发，则暂不作为跨职业构筑卖点，后续须扩展合法使用者或另行改稿。
- 锁环、洞察、沙眼属于“继承条件命中”同组，满足多个条件只取最高；现行剑术专注/远射专注保留可相加的既有行为。全体继承命中仍受+20上限限制。
- 新继承的效果须可独立说明。例如“仁心”只提高自己的有效治疗量，“祝福”由自己的有效治疗赋予目标下一次受伤-1，“咒法强化”仅延长自己施加的可延长减益。避免“己方”一词隐含全队光环。

### 5.3 12种标准示例构筑
| 构筑名 | 最终职业 | 推荐继承（按已解锁情况） | 核心玩法 | 克制 / 弱点 |
|---|---|---|---|---|
| 疾风游刃 | 影步剑客 | 身法 + 迅疾 | 通过速度追击、攻击后退位 | 怕无法撤退的角落 |
| 铜墙铁壁 | 盾誓骑士 | 枪卫架势 + 坚守 | 相邻护卫与减伤，稳步推进 | 怕魔法与多方向集火 |
| 逐风猎击 | 逐风游骑 | 远射专注 + 迅疾 | 靠机动调整射击位置 | 被枪特效克制 |
| 血斧压阵 | 黄昏处刑者 | 斧刃锐意 + 坚守 | 强斩低血量目标 | 未斩杀收益损失 |
| 炼狱枷锁 | 符阵师 | 咒法强化 + 炽纹 | 延长自己施加的可延长减益，攻击灼烧目标增伤；延长不增加法阵实体寿命 | 怕敌人绕行，灼烧本身不可延长 |
| 灵歌护队 | 祷歌师 | 阵心 + 魔力护幕 | 选择歌谣强化关键行动，同时靠站位提供邻友命中 | 分散作战降低收益，歌谣仍占行动 |
| 复合猎魔 | 星纹裁决者 | 迅疾 + 魔力护幕 | 剑近战可针对目标耐魔 | 黑次数与剑耐久双成本 |
| 双生战医 | 血契医师 | 仁心 + 祝福 | 有效治疗提高恢复量并给目标一次减伤；额外消耗自身HP仍需预览 | 遭突进击破，满血无收益 |
| 林影游猎 | 斥候 | 剑术专注 + 远射专注 | 林地移动、剑弓切换 | 草原暴露 |
| 旗墙联防 | 曙光旗手 | 枪卫架势 + 坚守 | 搭建可被破坏的防线 | 怕先拆旗 |

**合法性**：两个旧被动要先精通对应职业才能装备；双系最终职业必须满足两个武器等级与当前职业装备权限。若玩家尚未解锁这些职业/系统，界面应显示“未开放”而非虚构已可点击的槽位。

上表为目标构筑而非开局推荐；新被动必须等对应职业开放并精通后才可用。例如雷法连锁依赖上级职业精通，不能在刚开放雷链法师时宣称成型。未解锁时可用现行被动作过渡，但不得把相同的通用防御组合当成不同职业构筑深度的证据。

### 5.4 培养节奏与永久成长的验收

**保留现行规则**：职业成长率参与升级且可能影响永久属性；换职不会重算过去成长。九职业的成长补正、80/120精通阈值、主动+10/反击+5/待机+4职业XP均不在本次修改范围内。只待机时初级理论需20次、中级30次；这是需要测量的培养激励，不是漏洞修复承诺。

在新增职业开放前，使用相同初始角色与战役奖励，比较“按战术需要正常换职”“优先高成长职业升级”“拖延回合刷精通”三条路线，记录以下数据：

| 项目 | 验收要求 |
|---|---|
| 认证经济 | 按章列金币、凭证、名声来源与4人队伍认证支出；首批中级开放时能让每人至少认证1个职业，并留有至少2次队伍级试错认证预算 |
| 精通节奏 | 记录每章有效攻击、反击、待机数及各角色可精通数量；首批中级试验窗口暂定为2–3场正常关卡，再按实测调整未来阈值 |
| 拖回合收益 | 对照正常完成与额外待机的XP、资源和耗时；若拖延成为明显最优路线，另提公开规则调整，不临时暗扣XP或暗改现行待机收益 |
| 永久成长差距 | 比较固定10次升级后的期望属性与追击断点；在0–100%截断后实际成长率相差20个百分点，单属性期望差为2点，不能只用百分号判断影响 |
| 战术选择成本 | 验证玩家按地图换职是否因长期成长落后而被迫刷级；若明显出现“升级前必须换职”，优先降低未来新增职业成长差异，突出即时补正与固有 |

暂不引入追溯重算成长或补偿属性，也不把这些方案混入旧存档。所有新补给含兽哨、修理和考试凭证，都须在其职业开放之前有可持续且不依赖重复首通领奖的来源。上述节奏是试验目标，未经战役实测不称为已平衡。

## 6. 地形、敌军AI与可反制关系

| 新玩法 | 玩家收益 | 敌人如何反制 | 实施基础 |
|---|---|---|---|
| 骑兵冲锋 | 长距离建立优势 | 枪系特效与窄路、阻挡 | 骑乘寻路/标签、可停格 |
| 飞行机动 | 跨低障碍绕后 | 弓×3武器威力特效 | Flying标签/地形过滤 |
| 陷阱与法阵 | 改变敌人路线 | 显示危险范围、可绕开或清除 | 临时地形覆盖层 |
| 旗帜/路障 | 守路、拒敌 | 敌人可攻击旗帜/路障 | 中立可受击实体 |
| 拉拽/推挤 | 破坏敌人阵型 | 重型免疫、障碍阻隔 | 受控合法位移 |
| 辅助歌谣 | 强化一个关键行动 | 切断歌者/规避强化目标 | 状态系统与AI评价 |
| 召唤与野兽 | 临时堵位或侦察 | 远程击破或绕行 | 召唤单位AI、生命周期 |
| 献祭与低血量 | 强化爆发与治疗 | 压制施法者的生命安全 | 生命成本原子结算 |

**敌军规则**：新职业效果对AI与玩家同原则，不能只有玩家获益。AI需要计算负面状态、行动阻挡、护卫、召唤的威胁分数与预计收益；行为一致性与可解释性优先于复杂搜索。

## 7. 4张新机制验收地图

### 桥口防线

- 关卡：一条仅2格宽的桥，守卫与远程敌军；验证盾誓护卫、绳索拉拽、法阵与工事合法性。
- 地图须提供较长侧路或另一处渡点；仅有单桥而无侧路时不能宣称验收了绕后打法。远程敌人能攻击部署物，防止堵桥成为唯一解。
- 验收：同一地图至少可由正面破阵、绕后射击、阵地保护三种打法通关。

### 双翼崖谷

- 关卡：树林与可跨越低障碍、遮蔽区，加入1骑兵与1飞兵；验证移动模式与枪/弓克制。
- 验收：飞兵不能穿越禁飞格，弓特效倍率正确，骑兵不能忽视合法格限制。

### 暗灯遗迹

- 关卡：可交互机关、可破坏的旗帜及两处守卫法阵；验证支援与陷阱反制。
- 验收：陷阱不能叠出无限伤害，首领AI会选择可行绕路。

### 残血撤退

- 关卡：受损队伍遭精锐夹击，提供治疗与牺牲类战技、召唤堵路机会。
- 验收：血量消耗不致自杀，濒死保护不循环，治疗不刷经验。

### 7.1 首批职业试验矩阵

首批先验收影步剑客、盾誓骑士、祷歌师、灰烬术士四种决策，再开放绳索猎手、符阵师。可复用上述地图制作对照场景，不要求为每个职业额外制作一整张地图。

| 职业 | 正向场景 | 反制场景 | 必须观测的结果 |
|---|---|---|---|
| 影步剑客 | 攻击后退入掩护，避免暴露 | 撤退格被占或敌方封锁退路 | 退位不恢复攻击次数，预测列出合法退位与无法退位情况 |
| 盾誓骑士 | 替关键治疗者承受单体交战 | 多方向连续攻击或魔法集火 | 同轮只护卫一次，预览与实际承伤者、反击、追击一致 |
| 祷歌师 | 强化队友能跨越击杀/生存阈值 | 队友无法利用增益，直接攻击收益更高 | 记录放弃自己行动的机会成本，不额外产生完整行动 |
| 灰烬术士 | 对可存活到下阶段的目标施灼烧 | 目标即将被击杀或敌方净化 | 单个状态实例只结算一次、不致死；重施不能追加当期伤害或免除新行动成本 |
| 绳索猎手 | 拉出敌方阵型，供队友集中攻击 | 重型单位或落点不合法 | 控制失败不挪动目标，命中与伤害仍按已声明规则结算 |
| 符阵师 | 预判敌人必经通道再部署 | 敌人可绕路、清除或远程压制 | AI能够比较路径与清除代价，不能无脑走入危险格 |

通关仅证明可行，不证明平衡。对照替换为同层普通职业后的通关回合、承伤、资源消耗和核心能力实际使用次数；在至少一个反制场景中替代职业应有明确优势。首批每个职业至少记录正向/反制各3次固定种子运行，覆盖命中、未命中与关键追击断点，不以单次幸运结果通过。

### 7.2 五项边界规则验收清单（正式上线前必测）

| 编号 | 固定输入/操作 | 必须观测的结果 |
|---|---|---|
| CV2-G01 | 护卫者已经攻击或待机，且同轮首次遭遇合法单体攻击 | 仍可触发一次护卫；原单位不可被直接攻击，护卫不恢复普通行动 |
| CV2-G02 | 合法护卫触发但敌方首击未命中；同轮再次遭单体攻击 | 第一次即消耗额度，第二次不再护卫；预览/取消不消耗 |
| CV2-G03 | 两名护卫同时合法；或护卫者处于射程外/不邻接/被击败 | 多人按稳定ID择一；不合法者被排除；护卫者死亡不把后续攻击转回原目标 |
| CV2-P01 | 合法战技确认后首击未命中，或只打开预测后撤销 | 确认则费用仅扣一次；仅预测/撤销零消耗、零RNG、零XP；追击不重复扣费 |
| CV2-P02 | 护卫后命中、防护、护盾吸收、HP减少及可能保命 | 事件顺序固定，反击资格基于护卫者，实际承伤数值与预测概率一致 |
| CV2-C01 | 链枪打原本无缓足目标，首击命中施缓足；之后再打该目标 | 第一次没有+2，第二次攻击前已有缓足才+2；一份状态不叠层 |
| CV2-C02 | 链枪首击未命中，或同击「索缚」一起触发 | 未命中不施缓足；同击最多一份缓足，费用不重复 |
| CV2-S01 | 祷歌师分别在两种流派下使用三首曲调 | 每种流派三曲都可选、每次完整行动且总计2次白法术费用；只对应一首受流派强化 |
| CV2-S02 | 歌者已维持一首歌，下一轮换歌，或目标被施加同组歌曲 | 旧实例结束；不同歌者同组取最强；取消选择不变更当前歌曲 |
| CV2-S03 | 行歌目标路径预览、取消移动、确认移动；战歌/守歌无匹配事件到期 | 预算提前体现、取消不扣增益、确认后消耗；未触发则按所属阵营阶段到期；无额外完整行动 |
| CV2-F01 | 四人队伍分别以统领+1/+2/+3友军正交邻接；只对角或召唤物邻接 | 仅有至少2名合法真实邻友时阵旗生效，效果始终耐物+1且不叠层 |
| CV2-F02 | 阵型中一名邻友移走或死亡后又返回；移动预览取消 | 实际不足2人即时失效，恢复重新生效；仅预览不改变实际战斗效果 |
| CV2-F03 | 阵旗生效时原地使用结阵，或只有1名邻友使用结阵 | 相邻友军获得+2一轮，阵旗+1总防护受上限3约束；结阵至少一名邻友且消耗正常行动与枪耐久4，统领不自获+2 |
| CV2-F04 | 同关替换旗阵统领为同级壁垒卫士，采用集中与分散打法 | 对比承伤、站位机会成本、群体攻击风险和通关回合；验证集中站位确有独特收益与可执行反制 |

**执行口径**：每个用例至少覆盖合法与非法输入、玩家/敌军双方、固定随机种子、预览/确认/取消、旧存档与桌面/手机操作。新增系统测试应挂入 CI；未进入代码的职业暂只审查文档定义，不能将上述未来测试标成已通过。

### 8.1 开发数据约定（建议追加字段，不要破坏旧ID）
```ts
type ClassBlueprintV2 = {
  id: string;                 // 旧 class ID 不能重命名
  name: string; tier: "basic" | "intermediate" | "advanced" | "master" | "legacy";
  weaponCategories: readonly WeaponCategory[];
  requiredWeaponRanks: Partial<Record<WeaponCategory, WeaponRank>>;
  rankRequirementMode: "all" | "any"; // 游骑兵剑D或枪D使用any；其他默认all
  statModifiers: Partial<Record<BasicKey, number>>;
  moveModifier: number;             // 独立于现行BasicKey，移动最终至少1
  maxHpModifier: number;            // 预留，改变上限时同步约束当前HP
  growthModifiers: Partial<Record<GrowthKey, number>>;
  innateAbilityIds: readonly string[];   // 当前职业生效
  masteryRewardIds: readonly string[];   // 精通后解锁，需装备
  genericArtIds: readonly string[];      // 仍需学习和占通用槽
  classActionId?: string;               // 最多一个职业独占入口，可含互斥模式
  movementMode: "ground" | "cavalry" | "flying";
  requiredLicenseIds: readonly string[];
  unlockQuestId?: string;
  tags: readonly string[];
  masteryThreshold: number;
  releaseStage: string;
  implementationStatus: "candidate" | "prototype" | "released";
};
```

战斗效果单独注册 `EffectDefinition`（触发时机、筛选器、目标、资源、持续、叠加组、次数上限），不要在 `classes.ts` 按职业写特殊分支。`ClassBlueprintV2` 为建议接口，并不代表现有 TypeScript 已具备这些字段。

现行`BasicKey`不包含HP或移动，禁止把表中“移动+1/-1”直接塞进现有`statModifiers`后宣称生效。资格门槛与武器许可分别落表：`any`只放宽认证主专精，不能放宽当前职业许可或单件装备需求。纯信息、部署物、临时状态和技能资源都须独立数据化；资源引用保存稳定装备实例/法术/道具ID，而非仅写“耗次数”。

### 8.2 CI 与存档验收清单
- 职业ID不可冲突，职业总量按开放标签维护；未开放职业不能在真实转职界面出现可操作入口。
- 认证原子性：资格不足、法术资源不足、技能未解锁、道具不足均无副作用；考试消耗一次，旧认证反复切换不花钱。
- 武器熟练度、职业经验与角色等级独立；旧档九职业/旧精通ID保持；新增字段缺失按安全默认迁移，不丢人物属性、装备耐久。
- 决定性：相同输入与种子得到相同结果；预览纯读取；追击合法统一≥4，战技明确例外；普通物理不耗耐久。
- 路径：己方可穿越队友但不能占终点；敌方同理；飞行与骑乘各自过滤地形/敌方单位；动画始终沿合法路线逐格移动。
- 性能：一局上限有限的召唤/旗/法阵实体；攻击预览不递归推导无限联携；移动端与桌面端所有按钮都能关闭与撤销。
- 策划一致性：78候选ID唯一、层级7/27/28/10/6；每个已开放职业有职责卡、合法资源来源及正反例；继承的触发条件可达到，所有状态有事件时点，基础信息不被职业奖励锁住。
- 五项边界规则：参照§7.2的CV2-G/P/C/S/F用例锁定护卫额度、提交与结算顺序、缓足前置判定、三曲与流派、四人阵型；相同规则在AI与玩家侧使用单一权威实现。
- 部署：按 AGENTS / VERSIONING 每次代码提交同步 `src/version.ts` 与 `CHANGELOG.md`，等待 CI、浏览器验收和网站发布**全部完成**才报告“已完成”。

## 9. 当前需确认的策划决议（默认建议已填）

1. **总名录保留78种候选**，不等于版本2.0就实装78种；每期维护 `releaseStage` 与实现状态。重叠候选可先试作流派，但不擅自改旧ID。
2. **武器七系不扩张**，创造性靠混搭、能力触发、地形和职业联携。
3. **自由转职不等于无限无成本**：基础免费，中级及以上第一次认证消耗已明确资源；隐藏职业另需任务。
4. **新增角色职业固有**只在当前职业生效，已解锁的精通永久继承但受槽位上限限制。
5. **高等级职业更强但不全能**：强属性加成伴随资源、地形、射程或资格限制；任何高级控制都有反制。
6. **按依赖先 S1/C4，后 C5/C6/C7**；首批影步、盾誓、祷歌、灰烬，再在位移/地形基础就绪后验证绳索和符阵。
7. **冻结现行九职业/精通与待机XP**；本次只修改未来提案。职业成长的永久影响、待机培养效率和认证经济必须在战役流程中测量，必要调整另立方案。
8. **先验证决策价值再扩大名录**；基础战斗信息默认可见，职业奖励提供战术收益；不以资格昂贵替代战斗内代价。
