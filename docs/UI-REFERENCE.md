# 战场界面规范 · UI V1（参考图锁定）

本文件以用户于 2026-10-13 确认的“无顶栏、左上角设置、右侧全高状态栏”战棋概念图为视觉基准。
这是原创网页游戏的美术与交互规范，**概念图不是实际地图资源**；未完成的角色立绘、地形贴图、桥梁与营寨美术不能用整张概念图覆盖交互战场。

## 布局验收

- PC 页面不显示旧顶栏、品牌横幅、固定行动按钮或页脚，页面不产生纵向滚动。
- 地图填充左侧全部可用高度。右侧状态栏顶端紧贴顶部，底端贴近屏幕底部，不留大块空白。
- 左上角固定一个齿轮设置入口；返回游戏大厅、重新开始、重置视角、结束回合放在设置内。
- 右侧依次是“选中单位（头像、HP、四项核心属性与地形信息）”“战斗能力”“战斗日志”；版本号 **仅** 放右下角，动态读取 `src/version.ts` 的四段式 `GAME_VERSION`，不显示“单机原型”。
- 以深海军蓝底色、暗金边框、青蓝我军、赤红敌军、青色 HP 与淡蓝移动高亮为基础视觉色系。
- 单位、地形名称、属性与菜单必须用 DOM 文字，禁止把字体绘入经过整体缩放的低分辨率 Canvas。
- 较矮的 PC 窗口优先压缩内边距与日志可见条目，日志区域内部滚动；移动端允许右侧信息栏在战场下方滚动。

## 地图视角与交互

- 战场提供相机平移与缩放，不强制把整个地图缩小到屏幕内。鼠标滚轮以指针所在位置缩放。
- **右上角仅保留紧凑小地图**，不再显示旧的“− / 比例 / ＋”缩放控件与长条操作提示；小地图比旧左下角版本更小。缩放仍可通过滚轮或键盘 +/- 操作，限值 60%—185%，并限制相机拖出大面积空白。
- 左键拖动战场平移视角，拖动不可误触单位；点击小地图格子让镜头居中到目标。重置视角通过设置菜单或 M 键触发。
- **v0.1.20.4 新交互**：左键首次选友军只显示移动范围；再点合法目的格提交可撤销移动，待行走动画结束才自动显示攻击、背包、术法、交换、待机、取消移动菜单；再次点当前友军原位确认“原地行动”。右键短按试移动后直接撤回，移动前取消选中；右键拖动仍平移视角。
- 已实现：移动、指定可攻击目标、待机。道具、术法、交换仍未实装，显示禁用态及“后续版本开放”，不模拟不存在的战斗机制。
- “攻击”仅在当前有射程内目标时可用；选中目标后进入不直接结算的预测面板。**参考《火纹》左右对阵布局**：左我方右敌方、中央确定性伤害/反击数值、底部双色 HP 条、仅保留返回/攻击两个按钮，不写“确认后才会结算”等说明。由于当前无正式头像，可使用职业徽记占位，不伪造命中或必杀数值。
- 回合信息仅在开始与切换时通过短暂横幅显示于战场中央，不再固定占据顶栏。敌方回合切换后展示我方回合横幅。
- 按 Esc 关闭当前菜单；设置菜单支持关闭、返回游戏大厅、确认重开；胜负提示覆盖战场但不遮住设置入口。

## 敌军行动威胁范围

- 左键点击敌方单位时，紫蓝表示该敌军本回合按地形移动消耗、单位阻挡可到达的格子，红色表示从上述所有合法位置出发可以攻击的格子。两者重叠为蓝底红边；独立右侧信息栏仍显示敌方属性。
- 预览覆盖整个 10×8 可玩地图，遵循同一 `Battle.reachable` 加权寻路、同一兵种最小/最大射程，排除不能停留的峭壁及友方敌人占据的攻击目标格。
- 切换敌军时更新范围，点击空地/友军时清除；我方选择攻击目标以及底部攻击预测优先于敌军威胁范围显示。预览仅显示可能性，不改变 AI、战斗记录或血量。

## 代码边界与后续阶段

- `src/engine/battle.ts` 保留现有确定性战斗规则；UI 不得通过 DOM 操作绕开 `Battle.click` / `Battle.waitSelected` / `Battle.endTurn`。
- `src/scene/BoardView.ts` 承担视口、镜头、小地图、地图 DOM、地图指令的职责。
- `src/main.ts` 承担状态栏、设置面板、回合提示与日志的绑定。
- 正式地图美术独立制作或取得有效许可后替换程序化地形，不应将带有 UI、角色和提示横幅的完整设计稿当作底图。
- 角色正式立绘、物品、术法、交换、全局地图的独立放大查看和大地图可见区域裁剪属于后续开发，不得宣称已实现。战斗预测已具备当前规则的确定性伤害与反击显示，但还没有命中/必杀规则或正式角色头像。

## 验收场景

1. 在 1920×1080 / 1366×768 检查右侧状态栏完整显示，日志内部滚动，顶部无旧 Header。
2. 单击不同友军切换信息；移动、在射程内攻击、待机；验证每项仍按原规则生效。
3. 滚轮放大、缩小、边缘拖动、缩放后点击单位；地图点击定位正确，小地图白框更新。
4. 右键和 Esc 取消攻击模式；打开/关闭设置；确认重开；跳转游戏大厅。
5. 完成回合后只在切换瞬间显示回合横幅；无永久横幅。
6. CI TypeScript、战斗单元测试、生产构建通过后再观察 ECS `.source-sha` 是否切换到最新提交。

## 敌方主动攻击展示（v0.1.13.0）

- 每名敌军仍逐格移动、逐人结算。若计划攻击我方角色，移动动画结束后显示与我方主动攻击共用的底部火纹式对阵面板，**始终左我方、右敌方**。
- 敌方展示为自动流程，不显示玩家的“攻击/返回”按钮；最多停留 **5 秒**，左键单击屏幕任意位置可以立刻结束等待。点击会被捕获并阻止向战斗格或设置按钮继续传播，避免误操作。
- 5 秒倒计时或点击只结束**表现等待**，并不取消真实攻击；面板关闭后才通过原有 `commitEnemyAction` 结算一次命中、必杀、反击与经验，并在日志中生成一条完整行动记录。没有计划攻击的敌人不显示面板。
- 预览阶段敌方角色视觉上停留在计划终点，但引擎坐标/HP/日志仍维持未提交状态；预览结束后提交。重新开始关卡取消计时器/点击监听，旧回合失效，绝不让上一次攻击提交到新游戏。

## v0.1.15.0 武器 UI

- 右键我方单位后“攻击”先进入武器选择层，再进入地图攻击范围，继而选择目标、显示预测、确认。只有能攻击当前目标的武器可用于攻击选择；背包可自由预先切换本职业可用武器。攻击预测中展示双方当前武器。
- “背包”取代旧禁用的“道具”，侧边栏也为当前可行动友军提供装备切换，双方角色均显示真实所持武器。非本人、敌军、回合结束、动画中不可变更装备。
- 返回和 Esc 逐层回退；点击空地、右键关闭菜单都不重复发动攻击，战斗日志仍只记录完整行动。尚未加入回复药等消耗品。

## v0.1.16.0 移动设备适配

- 手机宽屏/竖屏采用全屏地图与底部四快捷键；右侧角色信息栏转为可关闭、独立滚动底部信息抽屉，防止查看角色时必须离开地图视野。
- 单指拖动地图、双指捏合以两指中心为锚缩放/平移。轻点友军选中，再点目的格移动，动画结束自动显示行动菜单；再次点当前友军或使用底部“原地行动”确认不移动；菜单“取消移动”及底部“返回”可回退试移动。点敌军查看行动/威胁范围，点武器、敌军目标并按原攻击确认流程。双指缩放期间的触屏点击不触发游戏格。
- 手机快捷栏包含“原地行动/指令、返回、信息、结束回合”，移动前选中友军时显示“原地行动”，移动完成后显示“指令”；后者执行与设置菜单完全相同的逻辑和条件校验；全部配合刘海、Home 指示条 safe-area。菜单/背包跟随缩放后的单位屏幕位置。
- 战斗预测固定在快捷栏上方，保持两侧 HP/伤害与确认按钮，敌方 5 秒自动预览可单击跳过。桌面端视觉与快捷键不变。

## v0.1.17.0 自动结束我方回合

- 所有**存活**我方角色完成待机或攻击后，自动执行与桌面设置/手机“结束回合”相同的敌方回合流转；按钮继续允许玩家提前结束当前回合，不强制逐一待机。
- 最后一名角色攻击时，先完整展示双方攻击、反击、追击及伤害，动画结束或一键跳过后才出现敌军红色阶段横幅。胜败结算中不自动切换。
- 执行期间只允许触发一次回合切换；异步回合被重新开始操作失效后不再提交旧回合行动。

## v0.1.18.0 我方可攻击范围

- PC 点击／手机轻点一名未行动友军时，蓝色为按加权寻路可到达区域，红色为使用当前装备从合法移动终点能够覆盖的攻击区域，蓝红重叠蓝底红描边。
- 移动结束后只显示从当前位置可攻击的格子；换武器后按照铁剑、投枪、长弓等实际射程刷新。攻击选择模式中仅允许对目前射程内的实际目标使用正式预测面板。
- 查看敌方单位时维持敌方紫蓝/红色威胁范围优先；行动完成、阵亡或敌方回合不再显示我方可行动区域；所有预览均不改变战斗状态。

## v0.1.19.0 光标悬停移动范围与路线箭头

- PC 鼠标移到任意友军/敌军角色所在格即显示**移动范围**（友军蓝、敌军红），无需点击，悬停阶段不显示原版整片攻击范围。
- 点击角色进入路线查看，移动鼠标到合法移动格，按真实地形最短花费路径绘制可缩放、随地图移动的黄色箭头；同时显示仅从当前鼠标终点能够覆盖的红色攻击格。光标进入别的角色格会临时显示该角色移动范围，不会自动改动正式选中状态。
- 点击空地不取消原有移动规则；敌军仅允许查看、不允许玩家直接移动。正式攻击仍通过行动菜单选武器与目标。手机维持触屏选择、移动和已有背包操作。

## v0.1.19.3 攻击范围颜色层级

- 移动范围为独立地图高亮层 z=45，攻击范围与正式目标为独立高亮层 z=46，路径箭头 z=47，角色 z=50；两个高亮层使用相同 10×8 战场格坐标并禁用指针响应。
- 蓝红重叠时下层蓝色清空，上层红色优先显示，保留地形纹理的透视而不混成紫色。
- 悬停与选中后的预览规则、点击战斗目标和手机操作方式维持不变。

## v0.1.20.4 桌面／手机操作验收

1. 点击未行动友军仅显示可达范围，不提前开启菜单；鼠标悬停仍预览移动路径和可攻击区域。
2. 点击可达目的格完成一次可撤销的试移动；路径走完后自动显示操作菜单。途中不能产生多次移动或指令。
3. 点击已选角色所在格可确认原地攻击／背包／待机。手机快捷栏另设“原地行动”，不会产生移动或撤销记录。
4. 桌面右键短按任意地图位置撤回本次移动，右键拖动仍平移；手机通过底部“返回”或菜单“取消移动”回到原点。攻击／武器选择层仍按返回层级逐步返回，但桌面右键可直接撤销试移动。
5. 攻击或待机提交后不能撤回完整行动。保持战斗结算、敌方 AI 和自动回合不变。
