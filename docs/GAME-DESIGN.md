# Wildfield Tactics · 单关卡玩法规范（MVP v0.1）

**Wildfield Tactics** 是当前英文暂定名。本游戏是原创奇幻战棋，并非《火焰纹章》同人或素材复刻。该系列只是**品类参考**，不能引用其角色、地图、职业名称、剧情或受版权保护的资源。

## 体验目标

玩家在网格地图上观察地形和双方兵种，通过移动、攻击顺序与反击射程取得局部优势，击败敌方指挥官。第一阶段强调**规则清晰、操作可预测**，再补复杂成长。

| 规则项 | MVP |
| --- | --- |
| 战场 | 10×8 正方形棋格 |
| 地形 | 土地（移动1/防御0）、草地（移动2/防御0）、树林（移动2/防御+1）、丘陵（移动2/防御+1）、峭壁（不可进入） |
| 部队 | 4名我方：剑士、枪卫、弓手、术士；敌军6名含统领 |
| 行动 | 我方整队行动完或点“结束回合”后进入敌方回合 |
| 单位 | 每回合最多移动1次、发动1次攻击；攻击后立即结束该单位本回合 |
| 攻击 | 曼哈顿距离；剑/枪1格，弓2–3格，术士1–2格 |
| 伤害 | `max(1, 攻击 - 防御 - 地形防御)` |
| 反击 | 防守者仍存活，且攻击者在防守者射程内，则立即反击 |
| 命中 | MVP 固定命中，不掷随机数，便于核对结算 |
| 占格 | 单位不可移动至任何其他存活单位的格子；障碍无法通行 |
| 敌军 AI | 先靠近目标；能攻击则优先攻击可击杀/残血目标 |
| 胜利 | 打败赤旗统领 |
| 失败 | 4名友军全部倒下 |
| 交互 | 点击蓝色友军选中；点击青色可达格移动；点击射程内红色敌军攻击；右侧可待机/结束回合 |

## v0.1.9.0 土地与草地

地图以 `.` 表示裸土地、`G` 表示草地。进入土地花费 1 点移动力，进入草地花费 2 点；移动消耗累计计算，可达范围和敌军移动都使用加权寻路。草地只提高移动消耗，不提供防御，不影响攻击或反击次数。每回合依然最多移动一次、攻击一次，未完成的移动仍可按既有规则撤销。

素材使用两张土地与两张草地变体，并根据实际地形数据绘制过渡边缘。棋格中心必须让玩家清楚识别地面；素材边缘过渡不增加隐藏的移动消耗。29 格草地形成较慢通行区域，裸土通道提供绕行选择，森林、丘陵、峭壁和出生点沿用原布局。

## 当前有意不做

角色永久死亡、命中/必杀随机数、角色经验升级、支援、转职、交易、装备耐久、对话及剧情演出、多关卡存档、联网同步。

不做的原因不是这些系统不重要，而是先验证一次 4v6 的战场决策是否有趣。上述内容分阶段加入，不能把未实现的内容写成已经可玩。

## 美术与界面

暂用程序绘制的地图色块、单位徽记与文字，不嵌入任何第三方游戏素材。后续原创或许可明确的素材统一登记来源及许可范围。

## 可验证的验收项

`npm run verify` 至少通过 TypeScript 类型检查、回合/寻路/战斗单元测试以及生产构建；浏览器人工检查移动高亮、攻击、敌人回合、胜败及手机缩放。未来如引入随机数，应加入固定种子重放能力。

## v0.1.12.0 角色能力与成长（代替早期固定命中、无成长限定）

基本能力：力量、防守、魔力、魔防、速度、幸运、技巧、魅力。战斗能力：物攻、耐物、攻速、耐魔、命中、回避、必杀、必避、射程；另有 HP、等级、EXP、移动、体格。九项成长率为八项基本能力加生命值，以独立 0–100% 判定，每满 100 EXP 升一级，最高 99 级。HP 成长提高 HP 上限并回复 1 点。魅力在未来计策/骑士团系统前不影响普通战斗。

以 Engage 式公式计算：攻速=max(0,速度-max(0,武器重量-体格))；命中=武器命中+2×技巧+⌊幸运/2⌋；回避=2×攻速+⌊幸运/2⌋；必杀=武器必杀+⌊技巧/2⌋；必避=幸运+武器必避；物攻=力量+物理武器威力，魔法攻击=魔力+魔法武器威力。耐物/耐魔分别从防守/魔防加既有地形防御计算。实际命中率=max(0,min(100,命中-回避))，必杀率=max(0,min(100,必杀-必避))。命中伤害=max(0,攻击力-防御力)，必杀造成三倍伤害。攻速差至少 5 时额外追击。死亡无法反击。预测不消耗随机数，预览 HP 是命中且不必杀的情境，真正结算用固定可重放的伪随机序列。经验暂定主动战斗 10，击败敌人加 25，被动反击 10。

## v0.1.15.0 武器库、背包与装备选择

早期“单一固定武器、背包未实现”仅对应旧 MVP。现在每名角色持有初始 3 件职业限定武器，背包最多 5 件；正式装备从自己的背包选择，切换装备不消耗移动或攻击，也不产生日志。武器数据维护于 `src/engine/weapons.ts`，当前有剑、枪、弓、斧和魔法的威力/重量/命中/必杀/必避/射程变体。装备行为在战斗引擎验证阵营、行动状态和职业相容性；不可装备敌方或其他职业的武器。物理/魔法、防御、攻速、命中/回避、必杀/必避、反击与攻击射程均通过当前武器派生，绝不按静态职业射程攻击；兼容旧测试的 `Unit.minRange/maxRange` 仅是同步镜像，不作为权威来源。

战术流程：右键可行动友军 → 攻击 → 选择有有效当前目标的武器 → 左键选择该武器射程内的敌方目标 → 火纹式战斗预测 → 确认攻击。预览阶段允许返回重新选武器，直到真正确认攻击前都不消耗行动。右键友军 → 背包 或侧栏背包可以切换装备；敌军保留职业初始装备并在攻击或反击时按自身实际装备计算。装备重量可能导致攻速降低、失去追击；长弓和投枪会改变实际射程。耐久、药品、治疗、交换、锻造及武器三角克制留待后续版本。

## v0.1.17.0 回合自动衔接

- 我方回合中，**所有存活友军**已完成一次攻击或待机，且战斗仍在进行时，自动开始敌方回合；阵亡单位不阻塞，零存活友军不触发自动推进。
- 每一名玩家攻击完成后先播放该次战斗的完整动画序列，最后一名友军结束动画（或玩家跳过）后再显示红色敌方回合横幅及进入敌军队列。待机没有战斗演出，可立即触发自动切换。
- 桌面设置／手机底部“结束回合”保留**主动提前结束**的能力，和自动触发共用同一 guarded 函数，避免重复启动敌军回合。胜利、失败优先于自动回合，敌方全部行动完后按原方式自动返回下一轮我方。
- 战斗引擎只提供是否全员行动完成的查询，回合 UI 负责等待动画并启动异步敌军队列；不改变 `Battle.endTurn` 供测试/无界面模式直接同步推进的历史用法。

## v0.1.18.0 我方移动与攻击预测

- 选中仍可行动的我方角色时，蓝色显示可移动位置，红色显示从全部合法移动终点使用**当前装备武器**能够攻击的格子；蓝红重合区域采用蓝色底与红色边框。投影使用加权移动消耗、单位占格、峭壁阻挡及武器最小/最大射程，并排除我方已占据的攻击目标格。
- 这是**移动后攻击可能覆盖的区域**，不等于此刻能直接攻击的目标；仍需正常移动及通过“攻击 → 武器选择 → 敌方目标 → 战斗预测 → 确认”来完成结算。选择正式攻击动作时仅高亮当前位置合法的攻击目标，不能点预测红格直接发起攻击。
- 移动后本回合只从当前角色格计算攻击范围；行动已完成、阵亡或非我方回合不展示。选择敌军查看时优先显示原敌军威胁范围；预览不会消耗随机数、经验或行动。

## v0.1.19.0 悬停与移动终点预览（替代 v0.1.18.0 即时攻击并集 UI）

- 鼠标移过任何存活角色的格子时，不需点击，显示该角色**仅可移动区域**：我方蓝色、敌方红色，不显示此时的整片攻击范围，避免信息遮挡地图。
- 点击我方角色（敌方可点击只读查看）锁定预览对象；然后鼠标移动到任何合法移动终点，显示该角色根据地形权重和格子阻挡生成的完整路线箭头，并显示**只从该终点**使用当前装备能够覆盖的攻击格。不再显示从全部可能终点出发的攻击并集。敌我预览都使用真实武器 min/maxRange 与战场障碍，绝不会改变逻辑位置、HP、RNG 或日志。
- 光标移到另一名角色格子时临时查看那名角色的移动范围；回到空格时恢复选中角色的终点预览。正式攻击仍按原菜单和当前实际位置进行，预览不会代替移动指令。触屏无悬停事件，继续通过轻点选择角色查看可移动范围。

## 后续目标：七系武器与自由职业系统（策划 V1.1，尚未实装）

完整的未来规则、数值、职业表、经济与验收见 [七系武器与自由职业系统策划](WEAPON-AND-CLASS-SYSTEM.md)，本文此前各版本段落保留为**当时的历史实现记录**，不自动替换当前代码语义。

**最终目标追击规则：**剑、枪、斧、弓、拳套、黑魔法与具有攻击效果的白魔法，均在双方攻速差绝对值≥4时由攻速较高的一方获得一次合法追击；防守方只有可以合法反击时才能追击。治疗与辅助白魔法不追击。剑系特殊之处仅为其追击伤害×1.2，并非唯一可追击的武器。战技默认按≥4追击，只有明确声明禁用的战技例外。武器三角取消，物理普攻和反击不消耗耐久，仅战技耗耐久，黑白魔法使用独立法术次数。

**W0实施（v0.1.20.11）：** 通用追击门槛现已由≥5改为≥4，预览与实际结算复用统一判定器。前文早期段落属于历史记录，剑追击增伤、拳套、黑白魔法使用次数、耐久及转职尚未实装。

## v0.1.21.0 — F0角色与职业数据解耦

- 游戏现有10个单位改由`CHARACTER_LIBRARY`的稳定人物ID建立，个人属性、成长率及起始装备与职业定义分离；`Unit.classId`为职业权限权威字段，`role`暂保留作历史兼容镜像。
- `CLASS_LIBRARY`按七系武器类别规定可装备权限，`WEAPON_LIBRARY`保留16件现有装备的原属性并补充武器类别和熟练度需求元数据；需求等级暂未强制执行，等待P1。
- 当前仅开放现有角色/武器。拳斗士和见习祭司是未上场的静态职业模板；不代表已加入拳套、白魔法、耐久、转职或任何职业能力效果。详见[F0架构说明](F0-DATA-ARCHITECTURE.md)。

## v0.1.22.0 — W1 七系武器固有机制与攻击魔法

- 通用追击攻速差≥4不变。剑系实际追击命中时，必杀计算后该次伤害×1.2向下取整；枪对Cavalry只倍增武器威力×2；弓对Flying只倍增武器威力×3；斧命中伤害至少5；拳套受到非拳套直接攻击回避+15。
- 黑魔法按魔力/魔防计算；新增白魔法攻击型“光矢术”使用魔法公式、射程与通用追击。恢复/增益白魔法和法术次数未开发。
- 新增仅用于测试的骑兵/飞行职业模板及拳套装备，原4v6第一关人数、初始背包、移动地形与操作不变。详细规则见[W1实现说明](W1-WEAPON-TRAITS.md)。
