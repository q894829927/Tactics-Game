# E1-1：战前武器商店与物品采购

## 功能与边界

正式战役「战前整备 → 选择角色 → 武器商店」中查看并购买武器或魔法书；属于现有装备物品采购，不增加未实装的药水/消耗道具。

- **货架**：18种已实现、玩家可使用的剑/枪/斧/弓/拳套/黑白魔法书。排除指挥剑（敌军专属）和任何未定义道具。货架库存不递减，价格固定、透明，暂不随机涨价。
- **购买条件**：当前角色所属职业允许使用该类别、武器熟练等级达标、金币足够、背包物品数少于5。所有条件在 `Battle.shopQuote` 预览和 `Battle.prepareBuyWeapon` 提交时独立校验，不依赖客户端按钮状态。
- **魔法书**：同种法术已有一件即禁止重复购买，因为当前魔法次数按法术ID共享；新增魔法书建立新的施法次数记录，但**不能**通过重复购买重置已有法术次数。
- **武器实例**：物理武器新建独立耐久与槽位ID；每个角色最多5件。购买只在末尾追加，不能覆盖转职时借用的训练武器；不自动更改当前装备。购入后通过上方「随身装备」手动切换。
- **支付与持久化**：交易仅发生在正式战役整备阶段。购买成功扣金币一次并触发原有本机存档；角色退出/刷新/出击/返回整备仍保留。金币不足或失效操作不会修改任何资金或背包。金币、名声、考试凭证不会互换。
- **展示与操作**：默认仅显示当前职业可使用类别，仍展示熟练度不足/金币不足/背包满的购买禁用原因；「全部商品」可以浏览其他类别并看到不适用提示。手机与桌面相同操作，不需要新界面层级。

价格是实验基线，不是完成数值平衡的证明。C4-1C四关首通共1220金币，正常四次中级职业认证共600金币，因此装备采购必须与维修、职业认证产生真实选择。若缺钱可继续出击，所有已购买物品不会强制要求继续消费。

## 结构和验收

- `src/engine/campShop.ts`：固定货架、价格和纯资格预览。
- `src/engine/battle.ts`：`shopQuote` 与 `prepareBuyWeapon`，无效购买无副作用，合法购买一次触发通知与持久化。
- `src/main.ts`、`index.html`、`src/style.css`：折叠货架、职业过滤、价格与购入明细、触摸按钮。
- `tests/e11CampShop.test.mjs`：单件购买、法术书、职业/熟练/资金/容量拒绝、借用武器不覆盖、保存恢复、真正出击拒买。
- `tests/browserE11Shop.mjs`：桌面和390×844手机从合法战前存档购买两次、钱包变化、满背包、刷新后再切换装备并真正出击。
- 不改 `CampaignSave.schema`：仍为1，复用旧存档 `inventory`、`weaponInstances`、`spellCharges`、`funds`。
