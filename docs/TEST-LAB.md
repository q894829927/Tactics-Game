# 综合测试地图（测试实验室）— 使用说明

状态：可独立访问，不属于第一章正式关卡。

## 入口与退出

1. 正常游戏进入「战前整备」，点击关卡选择区域的「进入综合试炼场」。也可以在游戏路径后加 \`?lab=1\`。
2. 在战场左上方的测试工具条选择预设（会完全重置当前测试），点击「重置预设」恢复全员 HP、状态、武器资源及位置。
3. 「返回战役」返回同一游戏路径并从原有浏览器存档恢复。测试过程**不读取、写入或清除** \`wildfield-tactics.campaign.v1\`。

## 一张地图，四种测试预设

所有预设都使用固定的10×8地形：土地、草地、森林、丘陵、峭壁与曲折入口；4名友军和6名敌军，右上角统领为通关目标。

| 预设 | 主要内容 | 关键测试点 |
|---|---|---|
| 综合战斗 | 斧枪弓治疗 vs. 重甲、骑兵、射手、统领 | 普攻/反击/追击、装备切换、武器射程、治疗、AI回合 |
| 近战与克制 | 游剑士、壁垒卫士、斗技家、破阵战士 | 重甲/骑兵克制、七系战技、职业技、拳套、命中闪避 |
| 治疗与异常 | 秘术师、祈疗师、剑士、术士；伤员与护盾敌人 | 治疗、法术次数、异常·试验、弱甲/护盾、状态时效 |
| 地形与机动 | 游骑兵、斥候、精锐射手、拳斗士 | 地形成本、同队穿越、敌人阻挡、移动撤回、远射与骑兵奔袭 |

所有角色预设具备满足当前武器类别的C级熟练度；装备和双主动槽为临时测试用数据。所有伤员、护盾与异常等状态在重置时恢复。不会开放正式战役中尚未实现的新系统，也不会改变职业认证、商店和关卡奖励数据。

## 验收边界

- 试炼场依旧使用真正的移动、攻防预测、回合/敌军AI、状态/法术/耐久规则；不是任意改HP的伪演示。
- 与正式第一章四关完全隔离，不改变解锁、资源、职业养成、存档版本或服务器数据库。
- 单张10×8地图无法涵盖未来78职业和大型范围法术/动态增援；未实装的系统不得伪称测试通过。
- 更改预设或重置时不保留本次战斗行动与状态；本试炼场没有结算金币。
- 代码回归：\`tests/testLab.test.mjs\`；浏览器烟测：\`tests/browserLabAcceptance.mjs\`，同时验证手机视口、重置和存档不变。
