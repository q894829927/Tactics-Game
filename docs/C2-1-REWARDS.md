# C2-1：战斗奖励、备战资源与中级职业认证闭环

**版本：v0.1.29.0**。继承C2-0的同一张4v6原型地图、战前整备、战后结算和localStorage进度；不新增关卡或随机考试机制。

## 奖励规则与平衡（固定、确定性）

| 完成一场出击 | 金币 | 名声 | 中级考试凭证 |
| --- | ---: | ---: | ---: |
| 胜利（击败统领） | +200 | +40 | +1 |
| 失败（全队阵亡） | +0 | +0 | +0 |
| 未结束而放弃、重开或刷新 | +0 | +0 | +0 |

资源只在`Battle.checkResult`由`battle`转入`settlement`的**唯一终态事件**计算并累加，已发放数额进入`SortieSettlement.reward`。浏览器渲染、打开结算、点击“返回整备”、读取旧存档、重复调用检查函数不额外发奖励。战斗完成后即时写入当前浏览器本地存档，打开后仍可查看这一次奖励；资源数额不因切换地图、角色或职业而消失。

此版本资源有上限（金/名声均100,000,000，中级券100,000）；达到上限时按剩余容量发放，结算显示**实际到账额**，以确保存档持续通过验证。失败仍保留战斗中实际取得的人物/武器经验，不掉落金钱、名声或考试券，避免通过故意失败刷资源。

目前只有一个可重复出击的测试关卡，固定奖励方便验证职业成长，但重复刷相同关卡获取资源是原型阶段明确允许的行为。未来地图与战役关卡奖励应再进行独立平衡。

## 中级职业认证资源闭环

沿用C1的资格算法，不发明随机考试成功率：只有`classCertificationStatus`全部通过才能实际认证。

- **游剑士**：剑系熟练度≥D（40经验）、名声≥30、中级券1张、金币150。
- **壁垒卫士**：枪系熟练度≥D（40经验）、名声≥30、中级券1张、金币150。
- 名声为**门槛**而非货币，不在认证时扣除；认证扣金币150、中级券1。
- 每名角色有独立`classLicenses`。成功认证永久保留，之后切回该职业免费且不再要求相同考试材料；个人当前熟练度仍须符合武器等级许可。
- **一场胜利即可筹够一个中级职业认证的经济资源**，但目标角色仍需自己具备对应武器熟练度。原第一关初始剑士/枪卫已有本系C级，因此可立即测试完整闭环。两场胜利可支付两次认证，金币结余100，名声80。

## UI 与数据

- 战前整备显示当前金币、名声、中级考试凭证，始终从`battle.preparationFunds`取得。
- 战后结算展示本次金币/名声/中级券**实际发放**数量，同时继续显示人物等级经验和武器熟练度经验变化。
- 职业整备中级认证考试区复用已有名声、金币、券与个人熟练度条件判断；玩家取得足够资源后“确认转职”才会解锁，不单独提供赠送资源入口。
- `CampaignSave.schema`仍为1：此前C2-0已有的资源存档字段足够支持新经济。战后新增`reward`对象；历史C2-0的`pendingSettlement`无奖励字段时读取为**+0**，不追溯补发或拒绝整份旧档。
- 完整存档仍只保存在当前浏览器localStorage，无法进行账号或设备间同步。

## 验收

- 胜利固定200金/40名声/1券；失败无奖励；不通过点击按钮二次发放。
- 结算页刷新不重复发放；读取旧版C2-0待确认结算不补发；缺失或损坏的奖励结构被验证器拒绝。
- 单次胜利取得中级认证资格、成功扣除金币和券、名声不变；再次免费切换；第二次胜利可认证另一位角色。
- 浏览器资源余额真实可见；没有模拟考试成功率、随机奖励、未实现的奖励获取途径。
- 原W0–C2-0移动/战斗/存档回归，以及桌面1920×1080、1366×768、手机390×844验收均通过。
