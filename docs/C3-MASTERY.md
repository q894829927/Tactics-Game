# C3 职业经验、精通与可继承被动特技

**游戏版本 v0.1.30.0。** 当前C3只实现独立职业经验与可继承的被动特技，S1主动战技及技能槽升级不在本阶段。

## 进度规则

- 每名角色对每个职业独立记录`classExperience`，初级职业精通阈值**80**，中级职业**120**；达到上限后本职业经验封顶，解锁其一项被动精通奖励。角色等级与七系武器熟练度系统均独立不变。
- 已完成的主动攻击（包括未命中）获得**10职业经验**；确实参与了反击的我方单位获得**5职业经验**；主动待机获得**4职业经验**。一次战斗含追击时不额外重复获得职业经验；没有实际反击事件则不会获得反击XP。撤销移动、装备切换、预览、无动作不产生职业经验。
- 经验归当时所属职业；切换其他职业不会删除之前的进度及奖励。战后结算显示每人的职业经验增长；未结算的战斗刷新依照C2-0回滚到战前安全检查点。
- 每名角色最多同时**装备2项**已经精通解锁的特技，在职业整备右侧「继承特技装备」进行开关选择。**解锁不等于装备**，未装备不会产生效果。装备后转职仍保留，真正的战斗计算与预览均调用同一套修正。

## 九项已实现奖励

| 精通职业 | 奖励 | 实际被动修正 |
|---|---|---|
| 剑士 | 剑术专注 | 命中 +5 |
| 枪卫 | 枪卫架势 | 物理防护 +1 |
| 斧斗士 | 斧刃锐意 | 必杀 +3 |
| 弓手 | 远射专注 | 命中 +8 |
| 拳斗士 | 身法 | 回避 +5 |
| 术士 | 魔力护幕 | 魔法防护 +1 |
| 见习祭司 | 祈愿 | 必杀回避 +5 |
| 游剑士 | 迅疾 | 攻击速度 +1 |
| 壁垒卫士 | 坚守 | 物理防护 +2 |

这些数值均有可测的`CombatStats`行为。相同方向的两项技能可叠加，且最高只装备2项；已精通但没有装备的职业技能不会自动叠加。

## 数据与旧存档兼容

- `Unit`、`AllyProgress`增加独立`classExperience`与`equippedMasteries`；结算角色行增加`classExpGained`。在C2-0的版本化`CampaignSave`中跟随角色成长一起持久化，仍采用原本`schema=1`以保证现有本机记录可加载。
- **C2-0/C2-1历史存档字段缺失时**只为职业经验和装备特技初始化空对象/空数组，并为历史结算的职业经验增加初始化0；其余属性、等级、七系经验、战役资金、职业认证及装备完全保留。
- 对存在的新字段进行严格校验：未知职业、非法XP、超过该职业阈值、未知特技、未解锁却装备、重复装备与超过两槽均拒绝，避免伪造或不合法数据进入战斗。
- 职业收益和玩家战斗选项在`Battle`内校验及提交。正式页面可以通过职业整备切换人物，查看所有开放职业的进度、奖励、是否精通与装备栏；切换战斗界面/关闭页面后角色精通保持。

## 仍未完成

- 当前仅九项继承被动，并未开放完整S1战技、治疗技能、自由技能槽数量扩展和进阶/最上级职业。
- 目前地图仍是可重复出击的4v6原型关卡，待机也积累少量经验；正式经济和多关卡平衡需后续设计。
- `new Battle()`仍保持独立测试原型模式；浏览器战役默认启用C2-0的本机存档与出击流程。
