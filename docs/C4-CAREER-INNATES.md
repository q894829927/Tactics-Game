# C4：职业固有能力、中级职业扩展及骑乘基础

本阶段基线：v0.1.34.5。该文件以当前代码为准；职业V2.0图鉴中的候选代表战技/职业独占动作仍需独立实现。

## 实装范围

- **16个可认证职业**：7个基础职业，9个中级职业。新增的7个中级分别为破阵战士、精锐射手、斗技家、秘术师、祈疗师、游骑兵、斥候；游剑士与壁垒卫士仍保持旧职业名称、旧属性补正/成长率及既有继承精通数值。
- **16项固有能力**：每个可认证职业拥有自动触发且不占槽的专属固有；战斗预测与真实结算均调用`innateAbilities.ts`共享算法，范围包括命中/回避、近战减伤、对减益输出、有效治疗及森林站位、骑兵奔袭。
- **7种新继承精通**：破甲训练、稳定瞄准、闪转、咒法强化、仁心、驰击、林地熟练；需要对应职业经验达到120后解锁，占既有**两个**继承槽，且不改变九项旧精通的常数。
- **骑乘许可**：第一场出击胜利后获得永久`ridingPermit`，之后凭剑D或枪D、30名声、150金币、1张中级考试凭证首次认证游骑兵。骑乘职业移动力+1，但森林和丘陵进入成本+1；转换回步行立即失去 Cavalry 兵种标签，枪对骑兵威力×2自动成立。斥候需要剑D且弓E，持林地熟练可降低森林进入成本1，最低1。
- **永续数据**：职业认证及精通经验沿用C2/C3数据。许可新增可选布尔字段；旧存档根据此前累计胜场自动补齐，明确保存false的存档不会被覆盖。移动记录、回避目标、闪避蓄势属于战斗临时字段，不持久化。
- **经济前提**：当前原型仍只有首关循环的固定200金币/40名声/1张中级凭证奖励，每次首次中级认证消耗150金币和1张凭证。C4实现认证机制，但**没有**伪称已存在第2章、多关卡考核或免费批量凭证；后续章节开发需扩展资源获取。

## 固有规则边界

- 剑士专注只加强主动普通首击；枪卫邻卫需相邻存活友军；斧斗士/破阵战士仅在目标基础防守≥8时得命中；弓手/精锐射手要求尚未主动移动；拳斗士孤斗需无邻接友军。
- 术士识咒及秘术师蚀刻须对已经存在的减益目标施法；见习祭司/祈疗师治疗收益需要真实损失HP，满血无效治疗不刷经验。游剑士对曾主动近战攻击的指定目标额外回避至下一本方阶段；壁垒卫士仅在没移动且受到近距离物理伤害时减免。
- 斗技家成功回避后，在下一本方主动首击获得+1伤害；闪转继承在同一窗口提供首击命中+5。没有回避就不会触发，取消行动不得消耗；使用一次即清除。
- 游骑兵奔袭要求实际已确认的路径至少3格，撤销移动会清零。斥候站森林回避+10；森林寻路及路径重建使用完全相同的地形步进成本，预览不修改状态。
- 条件继承技能不套入常驻基础属性，均检查触发条件。未来职业特殊动作/职业联携及更严格叠加预算另行立项，而不在C4中以纯文本装作已上线。
