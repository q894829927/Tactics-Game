# S1-2 治疗与异常状态系统

## 已接入能力

- 单独类型化临时状态 `src/engine/statusEffects.ts`：灼烧、缓足、弱甲、弱咒、标记、护盾。战场状态仅保存在 Unit，关卡重开或返回战前整备清空，不增加旧存档字段。
- 治愈术 `healing-prayer` 属白魔法E级，最多6次，射程1–2；已将见习祭司的白魔法训练装备改成治愈术。治疗量为5+实际魔力的一半向下取整，不能对满HP治疗或获得无效职业经验。
- S1-0统一支援行动费用：白魔法治疗消耗1次，护盾试验消耗2次，黑魔法状态试验消耗1次。仅纯预览不扣除次数、随机种子与经验；正式确认占一个完整行动。
- 灼烧在目标**下一次所属阵营阶段开始**造成2固定伤害，最多降至1HP；上述阶段末到期。重复仅刷新持续时间，不追加本期伤害。
- 缓足使实际移动预算-1（拥有正数移动力时最低1；原本0移动力保留0）；弱甲/弱咒使衍生耐物/耐魔-2；标记使对该目标命中+5；均不叠层且于下一所属阵营阶段末移除。
- 护盾当前单次3点、最多5点，伤害先抵消护盾再扣HP；未用完也会在下次所属阵营阶段末到期，重复施加取同类较大值，不累加。
- 状态的可见性、AI效果（路径与伤害）与预测均应在战斗中保持一致，不能因为屏幕动画延迟而改变逻辑。
- 新能力只作为S1-2基础和测试入口。七系职业专属战技、净化、状态抵抗、复杂命中与护卫系统仍在后续阶段；不能把试验能力当成已开放职业技能。

## 实施约束

只改变战斗单位临时状态和白魔法训练物品来源；不更换七武器类别、原9职业数值、追击阈值、自由转职资格、C2持久化数据模式。

验收重点：满血禁止治疗/扣费；费用不足与非法友敌目标零副作用；护盾和反击/追击伤害结算；灼烧不致死且阶段仅触发一次；缓足真实影响寻路与预测；存档恢复后不保留临时效果。
