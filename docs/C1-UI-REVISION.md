# C1 职业整备界面 UI 调整 · v0.1.26.0

本轮只更换职业整备UI与真实数据展示方式，不修改C1转职资格、W0–P1战斗规则、技能奖励或背包资源经济。

## 三栏布局

- **人物栏**：展示当前4名我方角色、姓名、真实职业、真实等级，背景纹章使用纯CSS/字符装饰，不伪装成已有角色美术资产。
- **职业栏**：列表只包含`Battle.classChoices`已开放的七初级、两中级定义。状态区分当前职业／已认证／可转职／资格不足。未接入C3职业经验及精通，因此不显示伪造的已精通勾选状态，不显示任何模拟考试通过率。
- **考试区**：仅选择**尚未认证且实际要求认证资源的中级职业**时显示，按`certificationRequirements`、个人`weaponExp`与`preparationFunds`显示武器熟练度、名声、金币、考试凭证和是否满足。初级职业、已认证中级职业不显示，列表自动利用空出的空间。
- **详情栏**：短职业描述、等级徽章与认证状态。大装饰符号使用`CLASS_LIBRARY`职业武器系图标和CSS，不声称3D模型已经集成。

## 属性与成长切换

「基础能力」包括真实最大HP、力量、魔力、技巧、速度、防守、魔防、幸运、魅力、移动（共10项）；「成长值」包含HP及8个成长率（共9项）。当前与目标数值都由`effectiveClassStats`/`effectiveClassGrowths`对同一个角色数据派生。HP、移动在C1没有职业补正，转职比较保持不变。

- 上升：金色数字+▲；下降：蓝色数字+▼；不变：白色数字，无箭头。
- 同一职业前后能力和成长值一致，且转职按钮禁用。
- 不展示未经定义公式支持的“综合战力”。

## 技能与内容真实性

- 「武器系特性」只展示W1中已有真实武器类别机制（例如剑追击×1.2、拳套回避+15），不把它们误写成职业固有技能。
- 「精通特技」只显示当前未开放状态（C3）；在C3数据/装备槽实现前不伪造技能图标与描述。
- 不再显示重复的武器资格大面板、无价值页眉解释、底部说明长段落，也不把初级免费认证称为“考试通过”。

## 自适应与回归

桌面约束1920×1080及1366×768。三栏各自具有独立滚动/信息区域。手机390×844在同一模态弹窗中使用纵向排列，人物卡横滑、职业卡双列、信息面板下方浏览；没有横向溢出。

保留原有`#class-roster`、`#class-options`、`#class-preparation-details`、确认/关闭按钮的基础自动化接口。补充Playwright真实交互回归：同职业属性不变、初级不显示考试、未认证中级展示真实资源、拳斗士速度与成长率变化、实际确认转职并切回剑士。
