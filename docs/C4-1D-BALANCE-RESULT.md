## 解读

1. **不刷关可以通关**：8个无重玩样本全数通关，说明至少这些固定种子和此策略下，不能把重复刷简单关卡设置为前进前提。需要扩大真实玩家测试后才能论证普遍难度。
2. **职业认证资源充足**：常规无刷样本真实完成游剑士、壁垒卫士、精锐射手、秘术师的4次首次认证，按600金与4张券扣除后，仍有620金与2张券。资源不会因为这四次认证造成软锁。
3. **初级精通偏早到顶**：完全不换职的小队在进入第四关前四人已全部达初级精通上限，第四关四人的该职业XP增量均为0。继续提高初级经验上限未必是正确方案；应该鼓励切职、继承构筑或补足内容阶段目标。
4. **中级精通有可选重复挑战动力**：无刷认证路线四人中3人完成当前职业或既有职业精通，首关多刷2次可达到4人。两次同图重玩使金币+150、名声+16，但不会额外给中级考试券，因此重复挑战能加速培养但不是通关必需。
5. **局部难度值得关注**：简易贪心策略已能完整打通四关，第一关固定约4回合，第四关5–6回合。可能表明当前战役短、敌军行为尚浅；暂不直接加强敌军数值，先完善战技/治疗/敌军AI的真实对照后确定难度。
6. **金币结余还不能说明价格失衡**：维修、商店等资源消耗出口未实装；不能因为最终剩620金就随意降低奖励。

## 当前结论与门槛

- C4-1D **第一轮可重复的实战数据验证完成**：四关合法完整通关、资源足够、无需重玩已由样本支持。
- C4-1D **最终平衡验收仍未完成**：待加入高级战技和治疗策略、不同队伍构筑、更多随机种子/手工实玩样本，并建立可接受回合与阵亡范围。
- 当前**不修改** C4-1C 首通/重玩奖金额度及职业认证成本。下一步宜优先做敌军 AI/关卡难度曲线和战前经济消耗出口，再针对具体样本细调，而不是凭直觉缩减奖励。
