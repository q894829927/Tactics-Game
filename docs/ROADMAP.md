## 玩法深化 W0/F0 状态（2026-10-14）

- **W0 统一追击：已实施（v0.1.20.11）。** 游戏现有剑、枪、斧、弓和攻击魔法，双方攻速差绝对值≥4且具备合法攻击/反击资格时追击。预测与真实结算共用纯函数；预计能击杀但实际未命中时按真实存活判定追加攻击。
- **F0 角色与职业数据重构：已实施（v0.1.21.0）。** [数据迁移说明](F0-DATA-ARCHITECTURE.md)：人物独立身份与个人数值/成长、职业分类与装备权限、七种武器类别与16件旧武器元数据均已接通，保留角色职业名和战斗玩法原有行为。
- **W1 七系武器固有：已实施（v0.1.22.0）。** [W1实现说明](W1-WEAPON-TRAITS.md)：剑追击×1.2、枪对骑兵威力×2、弓对飞行威力×3、斧命中保底5、拳套受非拳套攻击回避+15；黑/白攻击法术以魔防结算。新增练习拳套、光矢术和仅用于验证特效的骑/飞职业模板，未改变原首关阵容。
- **W2 物理耐久与魔法次数基础：已实施（v0.1.23.0）。** [W2实施说明](W2-RESOURCE-SYSTEM.md)：独立武器实例耐久、0耐久降威/命中、普通物理攻击零消耗、攻击魔法按法术计次且追击不重复扣、引擎战技样例与状态栏资源显示。
- **P1 七系武器熟练度与装备资格：已实施（v0.1.24.0）。** [P1实现说明](P1-PROFICIENCY.md)：角色七项经验独立累计，E/D/C/B/A/S/S+门槛，装备要求职业与熟练等级均满足；初始持有钢制武器的旧角色通过显式C级初始训练保留原有装备。有效攻击/反击/测试战技获取XP，追击不重复。
- **C1 战前自由转职与职业属性：已实现（v0.1.25.0）。** [C1说明](C1-FREE-RECLASS.md)：7初级免费认证/重复换职；2中级职业资格/费用校验，原子提交与角色独立认证；自动提供一个可替换的E级训练武器槽位；只在第一回合行动前允许切换，不重置角色个人属性/成长或武器XP。
- **下一步 C2/C3：** 完善考试资源获取与职业经验/精通奖励，之后S1战技与白魔法治疗、E1金币/维修与跨关存档按阶段推进。

4. **D UI 细节与综合验收：** 小地图、回合横幅、布局精修、浏览器多分辨率回归与性能/部署检查。

**不要将本计划等同于开放 T2/T3 全部玩法开发。** 不存在的数据（等级、命中、必杀、魔防、装备、治疗术）必须先设计和接通引擎，不能在 UI 上写假值。

## 技术与部署约束

- 战斗规则：`src/engine/battle.ts` 独立于渲染层；地图战术交互和文字继续使用 DOM，复杂场景可在独立绘制层渲染。
- 构建路径：Vite `base=/games/tactics/`，避免和其他项目资源冲突。
- 部署：`main → CI → site → ECS` 已配置；ECS 线上更新需单独核对 `.source-sha`，网络不稳定时不把 GitHub 成功视作 ECS 已成功。
- 版本：遵守 [VERSIONING.md](VERSIONING.md)，每个提交更新 `src/version.ts` 和 `CHANGELOG.md`，其中四段式第二段只在特别大的里程碑通过验收后递增。

## C2-1（v0.1.29.0）战斗奖励与职业认证资源闭环

- 已实现首个原型战斗资源循环：胜利固定获得200金币、40名声和1张中级考试凭证；战败无额外经济奖励。资源进入C2-0持久化存档，胜败结算时显示，并避免重复发放。
- 一次胜利可为剑/枪D级角色支付一次中级职业考试（名声门槛30、金币150、中级凭证1）；个人认证保留，已认证切回免费。
- 下一阶段建议**C3职业经验与精通**；后续正式多关剧情和不同难度再单独扩展奖金与经济来源。详见[C2-1文档](C2-1-REWARDS.md)。
