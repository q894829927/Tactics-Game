# Tactics-Game 分阶段研发计划

| 阶段 | 目标 | 出口验收 |
| --- | --- | --- |
| T0 工程与规则 | TypeScript/Vite/Phaser、地图和纯逻辑战斗状态、单元测试、GitHub CI | 无类型错误，可构建，规则可测试 |
| T1 单关卡原型 | 地形显示、玩家点击移动、攻击/反击、敌人AI、回合切换、胜负重开 | 本机单浏览器完成 4v6 一整关 |
| T2 战棋深度 | 动作选择菜单、障碍和地形策略、武器克制及行动预览、敌人威胁区 | 规则清晰，AI 不会卡在墙角，平衡测试 |
| T3 成长和内容 | XP、成长率、职业差异、装备、第二关及剧情事件 | 可以持续玩至少 2 关并保存 |
| T4 美术和网页上线 | 原创角色/战斗动效、音效、独立 ECS 路径 /games/tactics/、Game-Portal 卡片入口 | 手机桌面可用，构建资源与 /games/rift/ 不冲突 |

当前实施 T0/T1 基础；**不进入 ECS 上线阶段**，不修改 `Game-Portal` 或 `Rift-Resonance`。

## 技术决策

- UI：Phaser 渲染战场 + DOM 渲染操作信息，适合先快速迭代。
- 规则：`src/engine/battle.ts` 独立于 Phaser，便于 Node.js 单元测试。
- 构建路径：Vite `base=/games/tactics/`；避免与占用 `/assets/` 的旧游戏发生资源路径冲突。
- 第一版不需要 Colyseus；后续决定是否加入多人合作或者回合对战。
- 依赖版本锁定、代码审查和游戏平衡测试为接下来的工作重点。
