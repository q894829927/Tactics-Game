# v0.1.20.9 地图补充素材

四张原始 PNG 由内置 `image_gen` 生成，完整最终提示词见 [prompts.json](prompts.json)。高角度俯视、左上主光照、橄榄绿植被与冷色阴影延续既有半写实手绘森林风格。原图保留真实 Alpha；运行时使用 Pillow 缩放、质量 88 的内容哈希 WebP，透明度与缩放后的原图逐像素一致。

| 原始素材 | 运行时最大宽度 | 接入用途 |
| --- | --- | --- |
| [tree-broadleaf.png](tree-broadleaf.png) | 384 px | 与针叶树混合的阔叶树，对应实际森林格与外围树林 |
| [shrub.png](shrub.png) | 256 px | 战术区外的低矮林缘灌木 |
| [stones.png](stones.png) | 256 px | 战术区外的少量小散石，不作为通行障碍 |
| [hill.png](hill.png) | 384 px | 实际 `H` 丘陵格的低矮草坡，仍可通行 |

新增 WebP 共 178,542 字节；十一张核心地图素材总计 1,032,742 字节，低于 1 MiB 总量限制。完整尺寸、来源 SHA、编码参数、字节数及 Alpha 验证见 [运行时清单](../../../public/assets/maps/red-banner/modular/manifest.json)。原始 PNG 不进入运行时下载。

`src/scene/mapScenery.ts` 从真实地形生成森林、丘陵与阻挡岩团；林缘灌木和散石全部在 10×8 战术区之外。主地图与小地图复用同一场景布局及 Blob URL。单位、点击区和行动范围位于素材之上。

技术状态为已接入，最终画风仍待用户确认。M1 河岸转角／端头、草土过渡图集和完整岸线拼接的人工验收继续保留为后续任务。

## 实机检查

内置浏览器在 1920×1080、1366×768 与 390×844 视口检查地表／水面加载、100 个景物解码、80 个战术点击格、主地图与小地图同步。桌面与手机布局下均实际移动岚锋进入 D6 丘陵，再用右键／底部返回撤回；丘陵信息为移动消耗 2、防御 +1。手机检查为视口尺寸验证，未模拟原生双指触控。
