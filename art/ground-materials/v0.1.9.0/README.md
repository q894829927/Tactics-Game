# v0.1.9.0 土地与草地素材组

四张原始纹理由内置 `image_gen` 生成，最终提示词见 [prompts.json](prompts.json)。这些是可复用地面材质，不包含关卡布局、单位或 UI。已完成技术接入，最终美术验收仍待用户确认。

| 原图 | 运行时 | 字节数 | 地形规则 |
| --- | --- | --- | --- |
| earth-a.png | ground-earth-a.*.webp，512×512 | 93,778 | 土地：移动 1、防御 0 |
| earth-b.png | ground-earth-b.*.webp，512×512 | 99,714 | 土地：移动 1、防御 0 |
| grass-a.png | ground-grass-a.*.webp，512×512 | 128,226 | 草地：移动 2、防御 0 |
| grass-b.png | ground-grass-b.*.webp，512×512 | 124,684 | 草地：移动 2、防御 0 |

四张地面材质合计 446,402 字节；加上已有树木、岩团和水面，七张核心素材共 854,200 字节。继续使用内容哈希 URL、共享 Fetch/Blob URL 和异步解码。原始 PNG 仅作为美术源文件保存，不加入运行时下载。

`src/engine/terrain.ts` 统一定义土地/草地移动成本、名称与防御值。`src/scene/groundSurface.ts` 依据游戏地形代码选择地表，`GroundPainter` 以纹理变体组装独立土层与草层，相邻草地合并，外露边缘用稳定随机细节与 4 单位羽化蒙版过渡。过渡由材质与蒙版运行时合成，没有另行宣称制作固定的全关卡背景图或完整过渡图集。

地图保留 10×8 规则网格，29 格为草地，41 格为土地，5 格森林、3 格丘陵、2 格峭壁保持原布局。移动成本对双方都生效，草地不额外增加防御或攻击限制。

完整接入画面见 `desktop.png`；`grass-inspection.png` 与 `earth-inspection.png` 分别验证“移动消耗 2”和“移动消耗 1”，两者均为防御 +0。`browser-verification.json` 记录实际点击结果：3 点移动力可以进入一格草地，连续进入两格草地超出预算；移动后右键“取消移动”能回到原土地格，未完成行动的日志数保持 0。新战斗预测 UI 与右上角小地图保留。
